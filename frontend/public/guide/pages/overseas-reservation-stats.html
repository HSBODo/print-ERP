사용자와 쓰임새

레거시 구글시트를 그대로 옮긴 표

해외 예약통계는 오래 구글 시트로 관리됐음. 국가그룹 × 채널 × 지표가 가로로 길게 늘어선 표인데, 그 그룹·채널 구성을 그대로 화면으로 옮겼음. 시트를 쓰던 사람이 그대로 읽을 수 있어야 하기 때문임.

쓰는 장면하는 일
국가별 채널 확인영미·중화·베트남·몽골 각각 어느 채널로 들어오는지 봄
문의 → 예약 전환채널마다 문의와 예약이 짝으로 붙어 있음
수치 보정자동 집계가 틀린 칸을 화면에서 직접 고침
⚠️ 이 화면은 셀을 직접 고칠 수 있음

대시보드에서 집계값을 사람이 덮어쓸 수 있는 거의 유일한 화면임. 해외 문의는 카톡·왓츠앱·위챗처럼 시스템에 안 남는 경로가 많아, 자동 집계만으로는 채워지지 않음. 일 행에서만 고칠 수 있고 월·주 행은 합계라 잠겨 있음.

구성 요소

영역구성동작
보기 단위월간 · 주간 · 주차 · 일간 · 전체예약통계_시력교정과 같은 5단 구성

셀 수정일 행만클릭 → 입력 → 저장. 월·주 행은 합계라 잠김
안내 문구툴바 우측전환 시점과 수정 가능 여부를 화면이 직접 말함
주간과 주차가 둘 다 있음

주간 = 그 달의 달력 주(1~5주), 주차 = ISO 연간 주차. 시트 시절에는 달력 주로 봤고, 다른 통계 화면은 ISO 주차를 씀. 둘을 다 두어 과거 방식과 현재 방식을 모두 볼 수 있게 했음.

29에이전시agency.*group_key='agency'—유입경로 = 에이전시, 또는 크리에이트립 인데 국적이 중화권이 아님. 국적보다 먼저 판정
30에이전시 › 문의agency.direct_*'direct_*'—크리에이트립이 아닌 에이전시 유입 전부
31에이전시 › Creatripagency.creatrip_*'creatrip_*'—유입경로 = 크리에이트립

분류 규칙은 서버 주석에 「초안 — 실측 검증 후 조정 예정」 으로 남아 있음. 규칙에 없는 유입경로 값(예: 영미 그룹에 페이스북·인스타그램 으로 적힌 행)은 전부 「기타」 로 몰림 — 실제 시트 값 분포는 확인 필요.
