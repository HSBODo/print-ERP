표 · 지표 정의

월 × 연도 단위의 집계 화면임. 행 단위 명단은 없고, 응답 1행 = 1개월임. 화면은 마트 mart_b2b_revenue_monthly 를 읽고, 마트는 배치(EtcMartJob)가 CRM 원천 SQL(sql/softcrm/etc/select-b2b-*.sql)로 적재함. 정의는 레거시 BCRM routes/b2b-corp-settlement.js(B2B 기업 정산)를 그대로 옮긴 것임.

화면에서 계산하는 지표

화면 라벨계산식분모가 0 일 때
건당 매출round(totalRevenue / caseCount) — 월 비교는 해당 월, 연도 비교는 12개월 합으로 다시 나눔0
지정 매출 비중designatedRevenue / totalRevenue × 100 (소수 1자리 %)0.0%
시력교정 매출 비중visionRevenue / totalRevenue × 100 (소수 1자리 %)0.0%
원천 SQL 구조에서 오는 확인 필요 사항
  • 수술비 중복 가능 — 수술비(O)는 날짜 제한 없이 「고객의 최근 수납일」을 읽으므로, 백내장 양안을 다른 날 수술하면 같은 수술비가 두 건에 각각 잡힘.
  • 검사 행이 누적 전액을 읽음 — 백내장 검사 행은 7종을 전 기간 누적으로 읽어 수술비(O)까지 포함함. 같은 고객의 검사 행과 수술 행이 모두 기간에 들면 금액이 겹칠 수 있음.
  • 지정 판정 기준이 다른 화면과 다름 — 이 화면은 CUSTOM.Level = 'G' 를 비지정으로 봄. 레거시 주간보고의 「수술지정비율」은 CUSTOM.VIP_CODE = '05'(지정) 기준이고, 테이블 카탈로그는 Level 을 고객 등급(V/G/S/R)으로 설명함. 지정의 수술 비율 기획과 기준을 맞춰야 함.
  • 추천인 이름 하드코딩 — 이상광 · 유연환 · 이재형 3명이 SQL 에 박혀 있어, B2B 담당 추천인이 바뀌면 코드 수정이 필요함.

레거시 정산 원본과 같은 구조를 옮긴 것이므로, 수치 확정 전 BCRM B2B 기업 정산 화면과 월 합계를 대조할 것.
