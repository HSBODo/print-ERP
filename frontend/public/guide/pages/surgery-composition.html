5

표 · 지표 정의

칼럼 27개 — 값의 성격이 두 가지임

표기뜻
숫자건수 또는 인원
%그 칼럼의 분모 대비 비중 — 분모가 칼럼마다 다름

같은 표 안에서도 % 의 뜻이 다르므로 세로로 더해 100% 가 되는 묶음이 무엇인지 확인해야 함 — 아래 컬럼 정의의 비고에 칼럼마다 분모를 적음. 값이 0 이면 '-', 아니면 「N (P%)」 꼴이고 % 는 정수 반올림임.

⚠️ PIOL 합계는 유형별 합산이 아님

PIOL 합계는 원천이 세어 준 DISTINCT 환자 수임. icl + tIcl + kpl + tKpl + viva 로 더하면 양안에 다른 렌즈를 넣은 환자가 이중 계상됨 — 2026-07 실측: 합산 168 vs 실인원 148. 표에서 렌즈 5종을 더해 PIOL 합계와 안 맞는 것은 정상임.
