개요 — 이 화면은 무엇인가

검사 중단(STOP_YN) 건을 사유별로 분류해 연·월별로 확인하는 화면임. 검사메모의 공백·약어·표기 차이를 보정한 키워드 자동분류 기준.

사용자와 쓰임새

왜 멈췄는지를 7개로 나눠 봄

중단률이 "얼마나 멈췄나"라면 이 화면은 "왜 멈췄나"임. 중단 건을 사유 7버킷으로 분해하고, 그 버킷을 다시 수술 불가와 잠정 중단 두 그룹으로 묶음.

두 그룹의 뜻이 다름

수술 불가 — 의학적으로 수술이 안 되는 경우. 다시 올 일이 거의 없음.
잠정 중단 — 지금은 아니지만 나중에 다시 올 수 있는 경우.
후속 관리의 대상이 완전히 다르므로 색으로 갈라 놓았음.

쓰는 장면하는 일
중단 증가 원인 찾기어느 사유가 늘었는지 봄
재유치 대상 파악잠정 중단 그룹이 다시 올 수 있는 사람들임
레포트 대조월간·주차 레포트의 「중단 사유」 도표와 같은 값임

표 · 지표 정의

정의의 정본

db/중단사유-분류-정의.md — 매핑 변경 절차와 검증 쿼리가 있음. 요약은 지표정의/3-전환율-중단율.md §4.

분류 원천 — 상담사가 고른 코드

중단 건(STOP_YN='Y')을 상담사가 드롭다운에서 고른 정형 코드 EXAM.CANCEL_CD(char(3))로 분류함. 코드 마스터는 CANCEL_CFG 임. 메모를 키워드로 뒤지는 방식이 아니라 코드 기반이라 재현성이 있음.

코드군이 두 벌임 — 1xx 와 3xx

같은 사유가 두 코드로 들어옴(1xx 검사 중단 / 3xx 같은 라벨 세트). 새 코드를 추가할 때 짝이 있는지 반드시 확인해야 함. 한쪽만 넣으면 절반이 기타로 샘.

라벨이 '불가'인데 잠정 중단으로 보낸 코드가 있음

117·304(불가_백내장FU), 127·311(불가_기타 각막병증)은 라벨이 불가_ 로 시작하지만 검토 결과 기타(잠정 중단)로 귀속하기로 결정했음(2026-07-15). 라벨을 그대로 따르지 않은 의도된 예외임.

⚠️ 함정 ① — ELSE 로 떨어지는 코드는 조용히 기타가 됨

운영에 새 CANCEL_CD 가 생겨도 에러 없이 기타만 부풀어 오름. 골든 대조에서 기타가 늘면 이걸 먼저 의심함.
검토를 마친 코드는 ELSE 에 흘리지 말고 WHEN 으로 명시해야 "검토해서 기타로 정한 코드"와 "몰라서 샌 코드"가 구분됨.

⚠️ 함정 ② — CANCEL_CD 는 이름과 달리 취소 플래그가 아님

이 쿼리에서는 중단 사유 코드로 쓰지만, 다른 쿼리들은 같은 컬럼을 취소 판정(ISNULL(e.CANCEL_CD,'') = '')에 씀. 한쪽 의미로만 알고 고치면 다른 쪽이 깨짐.

컬럼 정의 — 툴바 합계 2개 · 차트 막대 8개

화면에 표는 없고, 한 달을 고르면 합계 2개와 막대 8개를 보임. 조회 경로는 마트 mart_stop_reason_monthly 이고 2026-01 이후만 값이 있음.

버킷 판정은 뷰의 CASE 한 곳(exam_category='시력교정' AND exam_stop='Y' 일 때 cancel_code 매핑) ← list_exam.exam_stop/cancel_code ← EXAM.STOP_YN/EXAM.CANCEL_CD(LTRIM(RTRIM)). 화면 설명문의 「검사메모 키워드 자동분류」 문구는 구현(코드 기반)과 다름 — 문구 정정 필요.
