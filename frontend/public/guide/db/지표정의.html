1.2 공통 규칙

검사결과 테이블 기반 (시력교정=EXAM)

  • 날짜 기준: EXAM_DATE (char(10), YYYY-MM-DD) — 실제 검사일
  • 시력교정은 측정값 무관 — 병원 검사자 리스트 행수 기준이라 측정값 미입력 검사도 포함.
  • 순수 외래 유입 제외 (2026-07-30 확정) — 그날 검사(M) 내원도, 수술 연계(검사일 이후 수술예약/수술기록, 재수술 포함)도 없는 EXAM 행은 검사자가 아니다(외래·백내장 예약으로 와서 EXAM 행만 생긴 건). 판정 배경·월별 영향: 점검/시력교정-검사자_2026-06~07.md
  • 더 엄격한 "완료" 기준이 필요하면 STOP_YN='Y'(중단)·CANCEL_CD(취소)를 추가 제외.

예약 테이블 기반 (백내장)

  • 소스: RESERVATION 백내장검사 예약(RESERVE_FLAG='H'), 날짜 기준 RESERVE_DATE
  • 검사결과 테이블(Cataract_Exam)은 집계 소스가 아니다 — 상세 컬럼(적절IOL·견적가·검사메모) 조회용 LEFT 성격이다.
  • 상세 규칙은 §1.4 참조.

⚠️ 폐기된 기준 — "백내장은 추천 수술방법 존재(OPERATIONR/OPERATIONL)로 유효 눈 판정"은 2026-07-23 정의 교체로 폐기됐다. 레거시 원장과 다른 화면을 보고 있었다(5월 67 vs 골든 84).

EXAM + RESERVATION 분류 기반 (드림렌즈)

  • 소스: EXAM WITH(NOLOCK) 기준 행을 RESERVATION 렌즈센터 D 예약으로 분류
  • 상태: RESERVE_STATE IN ('I','H') — 예약(Y)·취소(C) 제외. 이 병원은 'I'에서 멈추므로 사실상 "내원(체크인)".
  • 날짜 기준: RESERVE_DATE
  • 정기검진(FU)은 제외.

1.3 시력교정검사

정의: 해당 기간에 시력교정 검사를 실제 받은 사람 수. 소스는 검사결과 테이블 EXAM (병원 "검사자 리스트(상담사별)" 화면과 동일 소스). EXAM에 섞인 드림렌즈는 제외.

항목값
소스EXAM (시력교정 검사결과, PK=CUST_NUM)
날짜 기준EXAM_DATE (char(10), YYYY-MM-DD)
측정값 필터없음 — 병원 검사자 리스트 행수 기준(측정값 미입력 검사도 포함). 엄격 "실시"분만 필요하면 RIGHT01/LEFT01 존재 추가
드림렌즈 제외같은 날 렌즈센터(RESERVE_FLAG='D') 예약만 있고 시력교정('M') 예약 없는 EXAM 배제
순수 외래 제외그날 검사(M) 내원 없고 수술 연계(수술예약 RESERVE_DATE≥검사일·취소 제외 / 수술기록 OPERATION_DATE≥검사일) 없는 행 배제 (2026-07-30 확정)
집계 단위사람 = COUNT(DISTINCT CUST_NUM) (EXAM은 고객당 1행이라 행수와 동일)

소스가 RESERVATION이 아니라 EXAM인 이유: 병원 공식 "검사자 리스트(상담사별)" 화면(FrmCounselExamList)이 시력교정을 EXAM+EXAM_DATE로 집계한다. "실제 검사 실시" 기준이며 백내장(Cataract_Exam)과 동일 구조다. RESERVATION(flag M) 예약기반 집계는 검사 실시와 불일치(과거 정의 843/805 → 본 정의로 교체). 드림렌즈 혼입 주의: EXAM에는 검사종류 구분 컬럼이 없어 드림렌즈(CRT/각막굴절교정) 검사가 섞여 있다. 같은 날 렌즈센터(D) 예약 기준으로 배제한다.

SELECT SUBSTRING(e.EXAM_DATE,1,7) AS ym,
       COUNT(DISTINCT e.CUST_NUM) AS visionCorrection
FROM EXAM e WITH(NOLOCK)
WHERE e.EXAM_DATE >= :from AND e.EXAM_DATE <= :to
  AND NOT (                                    -- 드림렌즈 배제
        EXISTS (SELECT 1 FROM RESERVATION rd WITH(NOLOCK)
                WHERE rd.CUST_NUM = e.CUST_NUM AND rd.RESERVE_DATE = e.EXAM_DATE
                  AND rd.RESERVE_STATE IN ('I','H') AND rd.RESERVE_FLAG = 'D')
    AND NOT EXISTS (SELECT 1 FROM RESERVATION rm WITH(NOLOCK)
                WHERE rm.CUST_NUM = e.CUST_NUM AND rm.RESERVE_DATE = e.EXAM_DATE
                  AND rm.RESERVE_STATE IN ('I','H') AND rm.RESERVE_FLAG = 'M')
  )
  AND (                                        -- 순수 외래 제외 (2026-07-30)
        EXISTS (SELECT 1 FROM RESERVATION rm3 WITH(NOLOCK)
                WHERE rm3.CUST_NUM = e.CUST_NUM AND rm3.RESERVE_DATE = e.EXAM_DATE
                  AND rm3.RESERVE_STATE IN ('I','H') AND rm3.RESERVE_FLAG = 'M')
     OR EXISTS (SELECT 1 FROM RESERVATION ro WITH(NOLOCK)
                WHERE ro.CUST_NUM = e.CUST_NUM AND ro.RESERVE_FLAG = 'O'
                  AND ro.RESERVE_STATE <> 'C' AND ro.RESERVE_DATE >= e.EXAM_DATE)
     OR EXISTS (SELECT 1 FROM OPERATIONDATA od WITH(NOLOCK)
                WHERE od.CUST_NUM = e.CUST_NUM AND ISNULL(od.OPERATION_DATE,'') <> ''
                  AND od.OPERATION_DATE >= e.EXAM_DATE)
  )
GROUP BY SUBSTRING(e.EXAM_DATE,1,7)
ORDER BY ym
  • 보조(엄격 "실시" 기준): 위 조건 + 측정값 존재(RIGHT01/LEFT01) → 측정 완료분만 02=1585 / 03=850 / 04=799 (데스크는 미입력도 세므로 기본 정의는 측정값 무관).
  • 검증 (병원 수기 대조, 종전 규칙): 02=1600(병원 1604) / 03=854(853) / 04=809(807) / 05=900. 04월은 병원 엑셀 826행 = EXAM 4월 전체와 1:1 대조로 확정. 드림렌즈 미제외 시 02=1611/03=873/04=826.
  • 2026-07-30 순수 외래 제외 반영 (새 규칙 실측): 01=1,864 / 02=1,595 / 03=849 / 04=804 / 05=897 / 06=947 / 07(~07-30)=1,044. 레거시 화면(FrmCounselExamList)은 순수 외래 유입을 계속 포함하므로 새 규칙과 월 2~5명 차이가 난다 — 수기 대조 시 참고. 판정 배경·제외 명단: 점검/시력교정-검사자_2026-06~07.md

1.4 백내장검사

정의: 해당 기간에 백내장검사 예약으로 내원한 고객 중 검안사가 배정된 사람을 집계. 사람 단위.

2026-07-23 정의 교체 — 눈(안) → 사람. 레거시 원장인 BCRM > 통계(C) > 통계_백내장_내원동기의 원본 SQL을 확보해 재현에 성공했다(6월 55/55 정확 일치). 종전 Cataract_Exam 추천 IOL 눈 기준은 다른 원장이었다 — 5월 67 vs 골든 84로 −17이 났고, 6월 56 vs 55는 단위가 우연히 근접한 것뿐이다. 골든 = 레거시 분류 백내장 + 중단. (F/U는 외래 추적이라 제외)

항목값
소스RESERVATION(FLAG='H') + CUSTOM 담당자
날짜 기준RESERVE_DATE (char(10), YYYY-MM-DD)
모집단RESERVE_FLAG='H' · RESERVE_JINRYO<>'3'(C_재검사 제외) · RESERVE_SEQ<>3(노안5진료실 제외) · RESERVE_STATE NOT IN ('C','Y') · CUST_NUM<>'9999999999999' · 테스트 고객명 제외 → DISTINCT CUST_NUM
포함 조건검안사(MY_OPTOMETRIST)가 EMPLOYEE에 매칭되는 사람
└ 상담사 = BS0808(BS미지정)레거시 분류 중단 → 포함

└ 검안사 없음레거시 분류 F/U → 제외
집계 단위사람

⚠️ EXISTS(EMPLOYEE)로 판정할 것. 레거시 원본의 (SELECT EMP_NAME ...) = (SELECT EMP_NAME ...) 패턴은 사실상 IS NOT NULL 검사다. MY_OPTOMETRIST IS NOT NULL로 옮기면 빈 문자열이 걸려 분류가 뒤집힌다(중단 65 / F/U 3).

SELECT SUBSTRING(CH.ym,1,7) AS ym, COUNT(*) AS cataract
FROM (
    SELECT DISTINCT B.CUST_NUM, SUBSTRING(D.RESERVE_DATE,1,7) AS ym
    FROM CUSTOM B WITH(NOLOCK)
    JOIN RESERVATION D WITH(NOLOCK) ON D.CUST_NUM = B.CUST_NUM
    WHERE D.RESERVE_DATE >= :from AND D.RESERVE_DATE <= :to
      AND D.RESERVE_FLAG = 'H'
      AND ISNULL(D.RESERVE_JINRYO,'') <> '3'
      AND ISNULL(D.RESERVE_SEQ,0) <> 3
      AND D.RESERVE_STATE NOT IN ('C','Y')
      AND B.CUST_NUM <> '9999999999999'
      AND NOT (ISNULL(B.CUST_NAME,'') LIKE N'%테스트%' OR LOWER(ISNULL(B.CUST_NAME,'')) LIKE '%test%')
) CH
JOIN CUSTOM B WITH(NOLOCK) ON B.CUST_NUM = CH.CUST_NUM
WHERE EXISTS (SELECT 1 FROM EMPLOYEE E WITH(NOLOCK) WHERE E.EMP_NUM = B.MY_OPTOMETRIST)
  AND ( B.MY_COUNSELOR = 'BS0808'
     OR EXISTS (SELECT 1 FROM EMPLOYEE E WITH(NOLOCK) WHERE E.EMP_NUM = B.MY_COUNSELOR) )
GROUP BY SUBSTRING(CH.ym,1,7)
ORDER BY ym

1.4.1 백내장예약률

정의: 백내장 추천 눈(안) 중, 백내장 수술예약으로 전환된 비율.

⚠️ 분모는 §1.4 백내장검사와 다르다. §1.4는 2026-07-23 사람 기준으로 교체됐지만, 예약률 분모는 레거시 월간보고(~60%대)와 맞추기 위해 종전 눈(안) 기준(Cataract_Exam.OPERATIONR/L)을 유지한다. 2024·2025 하드코딩값(CATARACT_RATE_LEGACY)도 눈분모 기준이라 3개년 비교가 정합한다. 사람 분모로 통일할지는 별도 결정 사항.

검사 예약등록일은 분자 아님. 백내장 검사건수 분모는 이미 같은 날 백내장 검사예약(H) 내원을 보조조건으로 요구하므로, 검사예약 존재 여부를 분자로 쓰면 사실상 100%가 된다. 예약률 분자는 반드시 수술예약(O) 이어야 한다. RESERVATION에는 좌/우 눈 구분이 없으므로 분자는 눈 단위로 증폭하지 않고, 검사자 리스트의 수술예약등록일 존재 여부처럼 고객/예약 건 단위로 집계한다.

1.5 드림렌즈검사

정의: 해당 기간 드림렌즈/렌즈센터 검사 건수. 검사자 리스트와 같은 EXAM 기준에서 같은 날 렌즈센터 D 예약만 있고 검사 M 예약이 없는 행을 집계.

항목값
소스EXAM + RESERVATION 분류
진료유형RESERVE_FLAG = 'D'
상태RESERVE_STATE IN ('I','H')
세부유형제한 없음
집계 단위COUNT(DISTINCT CUST_NUM) (사람단위) — 시력교정과 통일

2026-02만 보고 D/L 계열(1,5,7)로 좁히면 01·03·04월 시력교정 숫자가 더 흔들림. 현재는 원복하여 렌즈센터 D 전체를 드림렌즈 분류로 사용.

SELECT SUBSTRING(e.EXAM_DATE,1,7) AS ym,
       COUNT(*) AS dreamlensPersons
FROM EXAM e WITH(NOLOCK)
WHERE e.EXAM_DATE >= :from AND e.EXAM_DATE <= :to
  AND EXISTS (SELECT 1
              FROM RESERVATION rd WITH(NOLOCK)
              WHERE rd.CUST_NUM = e.CUST_NUM
                AND rd.RESERVE_DATE = e.EXAM_DATE
                AND rd.RESERVE_STATE IN ('I','H')
                AND rd.RESERVE_FLAG = 'D')
  AND NOT EXISTS (SELECT 1
                  FROM RESERVATION rm WITH(NOLOCK)
                  WHERE rm.CUST_NUM = e.CUST_NUM
                    AND rm.RESERVE_DATE = e.EXAM_DATE
                    AND rm.RESERVE_STATE IN ('I','H')
                    AND rm.RESERVE_FLAG = 'M')
GROUP BY SUBSTRING(e.EXAM_DATE,1,7)
ORDER BY ym
  • 검증: 02=11 / 03=19 / 04=17 / 05=23 명. 검사자 리스트 전체에서 분리한 값.

1.6 함정 (Gotchas)

  • 카테고리별 소스·단위 상이: 시력교정=EXAM/사람, 백내장=RESERVATION(FLAG='H')+CUSTOM 담당자/사람(2026-07-23 눈→사람 교체, §1.4), 드림렌즈=EXAM+RESERVATION 분류/사람. 코드·차트에 소스/단위 라벨 명시 필수.
  • 시력교정 소스 주의: 예약(RESERVATION flag M)이 아니라 검사결과(EXAM) 기준. 예약기반은 병원 공식 수치와 어긋난다.
  • EXAM에 드림렌즈 혼입: EXAM엔 검사종류 구분 컬럼이 없어 드림렌즈(CRT/각막굴절교정) 검사가 월 ~2%(11-21명) 섞인다. 같은 날 렌즈센터(D) 예약 기준으로 반드시 배제(미배제 873/826 → 배제 854/809).
  • 측정값 필터는 시력교정 기본 정의에서 미적용: 병원 데스크가 측정값 미입력 검사도 리스트에 세므로 행수 기준으로 맞춘다. 측정값 존재(RIGHT01/LEFT01) 조건은 엄격 "실시" 보조지표로만(측정분 1585/850/799). 백내장은 측정값이 아니라 추천 수술방법(OPERATIONR/L) 기준.
  • EXAM은 스냅샷(고객당 1행) → 과거 월 수치가 사후 감소: 고객이 나중에 재검사하면 EXAM_DATE가 덮어써져 원래 달에서 빠진다. 실측 월 -3~-5명(~0.3%) 수준. 과거 월 수치는 조회 시점에 따라 미세하게 달라질 수 있음.
  • 측정값 미입력 검사(월 ~12명): EXAM_DATE는 해당월인데 RIGHT01/LEFT01이 빈 검사. 병원 데스크와 본 정의(측정값 무관)는 포함, 엄격 "실시" 보조지표에선 제외.
  • 백내장 단위 혼동 금지: §1.4 백내장검사는 사람, §1.4.1 백내장예약률 분모는 여전히 추천 눈(안) 이다. 두 지표를 같은 단위로 착각하지 말 것.
  • Cataract_Exam은 SEQ 누적 (EXAM과 다름): 고객당 1행 덮어쓰기가 아니라 검사할 때마다 SEQ가 쌓인다. 2026-06 114건 중 13건이 2회차 이상, 최대 SEQ 3. 따라서 EXAM류의 "과거월 소급 감소" 드리프트는 Cataract_Exam에 해당하지 않는다. 백내장 검사수의 과거월 변동은 담당자 재배정(CUSTOM.MY_OPTOMETRIST/MY_COUNSELOR)이 원인이다.
  • 드림렌즈 분류 기준 주의: 02월만 보면 D/L 계열만 분리하는 기준이 맞아 보이나, 01·03·04월은 렌즈센터 D 전체 분리가 레거시 시력교정 수치에 더 가깝다.
  • 드림렌즈 상태값 I 단독: RESERVATION IN('I','H')는 사실상 "내원(체크인)"이며, 최종 집계는 EXAM 행 존재를 함께 요구한다.
  • 병원 수기집계와 ±오차 정상: 병원 자체 수치(시력교정 03=853/04=807 등)는 수기/엑셀 집계라 시스템 정의와 1~2% 차이는 자연스럽다.

       COUNT(*) AS oneDayExamCount
FROM EXAM e WITH(NOLOCK)
JOIN CUSTOM cu WITH(NOLOCK) ON cu.CUST_NUM = e.CUST_NUM
WHERE e.EXAM_DATE >= :from AND e.EXAM_DATE <= :to
  -- 2026-07-30: 중단/취소(STOP_YN·CANCEL_CD) 단서 제거 — 원데이 = 당일OP 예약 기준
  AND NOT (

    OR LOWER(ISNULL(cu.CUST_NAME, '')) LIKE '%test%'
    OR ISNULL(e.EXAM_MEMO, '') LIKE N'%테스트%'
    OR LOWER(ISNULL(e.EXAM_MEMO, '')) LIKE '%test%'
  )
  AND EXISTS (
    SELECT 1
    FROM RESERVATION r WITH(NOLOCK)
    WHERE r.CUST_NUM = e.CUST_NUM
      AND r.RESERVE_DATE = e.EXAM_DATE

      AND r.RESERVE_STATE IN ('I','H')

      AND LOWER(ISNULL(r.RESERVE_NUM, '')) NOT LIKE '%test%'

수술은 실제 수술일자 기준으로 집계한다. 수술예약일/예약등록일이 아니라 실제 수술 실행 테이블을 기준으로 함.

2.1 개요

카테고리소스 테이블날짜 기준집계 단위비고
시력교정수술OPERATIONDATAOPERATION_DATE사람 (DISTINCT CUST_NUM)백내장 수술 고객 제외

2.2 공통 규칙

  • 테스트 고객 제외: 고객명 테스트, test 포함 제외.
  • 무효 수술코드 제외: X, OP불가, 모든수술가능, op x, Strabismus, TEST-TEST.
  • 시력교정은 Cataract_Operationdata에 존재하는 고객을 제외하여 백내장 중복 혼입 방지.
  • 전체 수술건수는 세부 수술명 합산이 아니라 시력교정수술 인원 + 백내장수술 눈 수.
  • 세부 수술명은 양안에 서로 다른 수술명이 들어갈 수 있어 유형별 합계와 전체 인원이 반드시 같지 않음.

2.3 시력교정수술

정의: 해당 기간 실제 시력교정 수술을 받은 사람 수. 레거시 "시력교정 검사 후 수술" 표와 대조한 결과, 수술예약보다 OPERATIONDATA.OPERATION_DATE 실제 수술 기준에 가장 가까움.

SELECT SUBSTRING(o.OPERATION_DATE,1,7) AS ym,
       COUNT(DISTINCT o.CUST_NUM) AS visionPatients
FROM OPERATIONDATA o WITH(NOLOCK)
JOIN CUSTOM cu WITH(NOLOCK) ON cu.CUST_NUM = o.CUST_NUM
WHERE o.OPERATION_DATE >= :from AND o.OPERATION_DATE <= :to
  AND NOT EXISTS (
      SELECT 1
      FROM Cataract_Operationdata co WITH(NOLOCK)
      WHERE co.CUST_NUM = o.CUST_NUM
  )
  AND (
       (NULLIF(LTRIM(RTRIM(ISNULL(o.OPERATIONR,''))), '') IS NOT NULL
        AND o.OPERATIONR NOT IN ('X','OP불가','모든수술가능','op x','Strabismus','TEST-TEST'))
    OR (NULLIF(LTRIM(RTRIM(ISNULL(o.OPERATIONL,''))), '') IS NOT NULL
        AND o.OPERATIONL NOT IN ('X','OP불가','모든수술가능','op x','Strabismus','TEST-TEST'))
  )
  AND NOT (
      ISNULL(cu.CUST_NAME, '') LIKE N'%테스트%'
      OR LOWER(ISNULL(cu.CUST_NAME, '')) LIKE '%test%'
  )
GROUP BY SUBSTRING(o.OPERATION_DATE,1,7)
ORDER BY ym

2.4 백내장수술

정의: 해당 기간 실제 백내장 수술 눈 수. 우/좌 수술일을 펼친 뒤 CUST_NUM + OPERATION_DATE + R/L을 1건으로 집계. 동일인이 같은 날 양안 수술하면 2안으로 집계.

SELECT SUBSTRING(x.OPERATION_DATE,1,7) AS ym,
       COUNT(DISTINCT x.CUST_NUM + '|' + x.OPERATION_DATE + '|' + x.eye) AS cataractPatients
FROM (
    SELECT CUST_NUM, OPERATIONR_DATE AS OPERATION_DATE, OPERATIONR AS OPERATION, 'R' AS eye
    FROM Cataract_Operationdata WITH(NOLOCK)
    UNION ALL
    SELECT CUST_NUM, OPERATIONL_DATE AS OPERATION_DATE, OPERATIONL AS OPERATION, 'L' AS eye
    FROM Cataract_Operationdata WITH(NOLOCK)
) x
JOIN CUSTOM cu WITH(NOLOCK) ON cu.CUST_NUM = x.CUST_NUM
WHERE x.OPERATION_DATE >= :from AND x.OPERATION_DATE <= :to
  AND NULLIF(LTRIM(RTRIM(ISNULL(x.OPERATION,''))), '') IS NOT NULL
  AND x.OPERATION NOT IN ('X','OP불가','TEST-TEST')
  AND NOT (
      ISNULL(cu.CUST_NAME, '') LIKE N'%테스트%'
      OR LOWER(ISNULL(cu.CUST_NAME, '')) LIKE '%test%'
  )
GROUP BY SUBSTRING(x.OPERATION_DATE,1,7)
ORDER BY ym

3. 산출물 저장 전략 — 주간 승인 + 월 마감 스냅샷

확정 방침(2026-08-05): 드리프트 제거는 주간 승인 → 월 마감 스냅샷으로 한다. 종전 초안의 "2026년 이후 전 지표 일별 산출물 저장 후 합산" 은 폐기한다 — 일별 저장은 범위 밖이다. (구 db/지표-마감스냅샷-기획.md 를 이 절로 흡수하고 그 문서는 삭제했다.)

3.1 왜 필요한가

  • EXAM 은 고객당 1행 스냅샷 → 재검사하면 과거월 수치가 사후 감소(§1.9.1.1).
  • RESERVATION 상태값(I/H)은 늦은 내원·정정으로 과거월 행수가 사후 증가 (외래수 2026-01 레거시 4,822 vs 현재 4,831).
  • 백내장 분류는 CUSTOM 의 현재 담당자 값을 보므로 재배정 시 지난 달이 바뀐다(§1.4).
  • 지금도 2024~2025 는 시드(=수동 스냅샷) 로 고정 중이다. 이걸 테이블로 정식화하는 것이 목표다.

  • 합계 ≠ 총검사자 — 2024~2025 한정. 검사 건수 블록이 별도 집계라 어긋났다(예: 2024-04 합계 1,167 vs 총검사자 1,140). 2026-06 이후로는 일치한다 — 개편으로 검사수의 백내장 몫이 리스트 전체(102)가 되면서 시력교정 + 드림렌즈 + 만 + 노안2 = 총검사자 가 성립한다. 검산(2026-07): 1,074 + 28 + 56 + 46 = 1,204 = 검사수(§1.9.1) ✓
  • 검사 비율 5칼럼 ≠ 검사 건수 4칼럼 — 비율 블록은 노안을 별도로 두어 분류가 다르다. 분모는 합계.
  • 만(56)과 검사수의 백내장 몫(102)을 섞지 말 것 — 종합표 안에 두 숫자가 같이 있다. 월간 레포트·/stats/cataract-exam-list 요약 칩의 "백내장검사수"는 만(56) 이다.
