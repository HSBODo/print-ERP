## 다시 생성하기

메뉴가 늘거나 API가 바뀌면 문서를 손으로 고치지 말고 다시 생성한다.

```bash
cd _build
node scan.mjs     # 레포 코드 → spec-data.json
node gen.mjs      # spec-data.json + content/ → ../prd.html 「전메뉴 현황」 구간 치환 + ../pages/*.html
node render-metric-docs.mjs # 지표정의/*.md → 브라우저용 지표정의/*.html
```

Node 18+ 면 되고 의존성은 없다. **레포 경로는 [_build/config.json](_build/config.json) 에 있다** —
레포를 옮기거나 다른 PC에서 돌릴 때 거기만 고친다(환경변수 `DASHBOARD_REPO` 가 있으면 그쪽이 우선).

`gen.mjs` 는 prd.html 전체를 다시 쓰지 않는다 — `<!-- GEN:menu-status -->` … `<!-- /GEN:menu-status -->`
마커 사이(「전메뉴 현황」 탭 본문)만 갈아끼운다. PRD 본문 등 손으로 쓴 부분은 건드리지 않는다.

각 메뉴 문서의 **1·6·7·8·9장**(개요·데이터 소스·API·권한·연관 문서)은 코드에서 자동 생성되고,
**2·3·4·5·10장**은 사람이 쓴 것으로 `_build/content/<id>.mjs` 에 산다.
재생성해도 손으로 쓴 본문은 살아남는다.

자세한 내용은 [_build/README.md](_build/README.md).
