지표정의 — 환자 흐름별

환자가 병원을 거치는 순서대로 지표를 정리한 문서 묶음임. 각 문서는 그 지표가 무엇으로 이루어지고, 데이터를 어디서 가져오는지를 표로 보여줌.

예약  →  검사  →  전환율 / 중단율  →  수술  →  외래
                  └ 예약률 (검사자 → 수술예약)
#문서무엇을 세나소스 테이블세는 단위
1예약검사받으러 오기로 한 사람RESERVATION (M)예약 건
2검사실제로 검사받은 사람EXAM · RESERVATION(H)사람
3전환율·중단율수술로 이어진 비율 / 멈춘 비율EXAM + 수술 예약·기록비율
4예약률검사자 중 수술 예약까지 간 비율EXAM · RESERVATION(H,O)비율
5수술실제로 수술받은 사람OPERATIONDATA · Cataract_Operationdata · RE_OPERATION사람 / 눈 / 건
6외래수술 후 경과 보러 온 사람RESERVATION (F)건

먼저 알아둘 것

집계 단위가 지표마다 다름. 단순히 더하면 안 됨.

단위해당 지표
사람시력교정검사 · 드림렌즈검사 · 백내장검사 · 시력교정수술
눈 (좌/우 각각)백내장수술
건예약 · 외래 · 재수술

기준해당 지표
