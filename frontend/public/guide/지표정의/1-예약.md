# 지표정의 1 — 예약

> 환자 흐름(**예약** → 검사 → 전환율/중단율 → 수술 → 외래)의 첫 단계.

## 한눈에 보기

예약은 **모두 `RESERVATION` 한 테이블**에서 나옴. `RESERVE_FLAG` 로 종류가 갈림.

| 코드 | 종류 | 다루는 문서 |
|---|---|---|
| **`M`** | **검사 예약** | ✅ **이 문서** — 「예약」이라 하면 보통 이것 |
| `H` | 백내장검사 예약 | [검사](2-검사.md) |
| `F` | 외래 예약 | [외래](6-외래.md) |
| `O` | 수술 예약 | [수술](5-수술.md) |
| `D` | 렌즈센터(드림렌즈) | [검사](2-검사.md) |

### 검사 예약(`M`)의 조건

| 항목 | 값 |
|---|---|
| **테이블** | `RESERVATION` |
| **구분** | `RESERVE_FLAG = 'M'` |
| **진료구분** | `RESERVE_JINRYO IN ('', '5', '6', '7', '24', '25')` |
| **날짜** | ⚠️ **`InsertedDateTime`(등록일)** — 예약일이 아님 |
| **세는 단위** | 예약 건 (`COUNT(DISTINCT RESERVE_NUM)`) |
| **테스트 제외** | 고객명 `테스트`·`TEST`, 고객번호 `8888888888888` |

> ⚠️ **왜 예약일이 아니라 등록일인가** — 예약일로 세면 **다음 달 예약이 이번 달에 섞여**
> 차트와 어긋남(특히 2월 +20%). 등록일은 미래가 불가능해서 **당월까지 자연스럽게 완결**됨.

> ⚠️ **취소(`STATE='C'`)를 빼지 않음.** 등록 시점 기준 집계라 취소 여부와 무관하게 셈.

## 1. 채널 구조

```
예약 종합
├─ 콜      = 인콜(CTI) + 아웃콜(CRM)
└─ 온라인  = 홈페이지(ONLINE) + 앱(APP) + 네이버(NAVER)
```

`RESERVE_PATH` 값으로 구분함.

| 그룹 | `RESERVE_PATH` | 표시명 |
|---|---|---|
| **콜** | `CTI` | 인콜 (걸려온 전화) |
| | `CRM` | 아웃콜 (건 전화) |
| **온라인** | `ONLINE` | 홈페이지 |
| | `APP` | 앱 |
| | `NAVER` | 네이버 |

**두 그룹은 서로 배타적**이라 콜 + 온라인 = 종합이 성립함.

### ⚠️ 콜에만 붙는 추가 제외 조건

콜은 **B2B(군인) 단체예약·재검·중복·시뮬·차트있음**을 뺌(`RESERVE_SEQ` 8·5 및 메모 문자열).
**온라인은 빼지 않음** — 군인 단체예약(월 ~80건)이 콜로만 들어오기 때문임.
온라인에 같은 제외를 걸면 과소 집계됨.

> 카카오(`KAKAO`)는 해피톡 채널이라 `RESERVATION` 에 거의 안 들어옴. 온라인 합계에
> 실질적으로 미포함이고, 레거시 차트도 마찬가지임.

---

## 2. 어느 값을 쓰나

| 기간 | 처리 |
|---|---|
| **2024 ~ 2025** | **레거시 확정값 고정** (DB 재집계 안 함) |
| **2026 이후** | **DB 라이브 계산** |

2026 실측은 레거시 차트와 **월 ±1~3%** 로 일치함. 잔차는 차트가 특정 시점 수기 export 라
생기는 스냅샷 드리프트임. **공식 표시값은 DB 라이브 값을 씀.**

> 레거시 원본 화면은 콜센터 MySQL 인입콜·TM·해피톡을 함께 합친 값이라 완전 재현이
> 원리적으로 불가능함. 이 정의는 `RESERVATION` 경로 기반 **근접 추정치**임.

## 3. 관련 화면

| 화면 | 경로 | 내용 |
|---|---|---|
| 예약 종합 | `/stats/reservation-overall` | 3탭 — 종합 / 온라인 / 콜 |
| 예약자 리스트 | `/stats/reservation-list` | 등록일 기준 명단 (채널·상담사·의사·메모) |
| 예약통계_시력교정 | `/stats/reservation-stats-system` | 주차별 채널 분해 (스냅샷 + 라이브) |
| 예약통계_백내장 | `/stats/reservation-stats-cataract` | 스냅샷 전용 |

> **예약자 리스트는 위와 완전히 동일한 조건**을 씀.
> 리스트 행 수 = 예약 종합 건수가 되도록 맞춰져 있음.
