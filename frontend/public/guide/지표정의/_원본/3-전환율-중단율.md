# 지표정의 3 — 전환율 · 중단율

> 환자 흐름(예약 → 검사 → **전환율/중단율** → 수술 → 외래)의 중간 단계.
> 검사받은 사람이 **수술로 이어졌는지 / 중간에 멈췄는지**를 봄.
> 분모가 되는 검사 정의는 [검사](../2-검사.md) 참조.

## 한눈에 보기

**검사받은 사람이 거치는 단계마다 비율이 하나씩 나옴.**

```
검사받음  →  상담함  →  수술 예약함  →  실제 수술함
   │           │            │
   └ 중단률    └ 상담성공률   └ 전환율
```

| 지표 | 분자 ÷ 분모 | 대상 | 화면 |
|---|---|---|---|
| **상담성공률(전환율)** | 수술 예약한 사람 ÷ 상담한 사람 | 시력교정 | `/stats/consultation-rate` |
| **백내장 예약률** | 수술 예약한 사람 ÷ 백내장 검사자 | 백내장 | `/stats/cataract-reservation-rate` |
| **중단률** | 중단한 사람 ÷ 시력교정 검사자 | 시력교정 | `/stats/stop-rate` |
| **중단 사유** | 중단 건을 7개 사유로 분해 | 시력교정 | `/stats/stop-reason` |

---

## 1. 시력교정 — 상담성공률 / 전환율

| 항목 | 내용 |
|---|---|
| **테이블** | `EXAM` + `RESERVATION`(수술) + `OPERATIONDATA` |
| **날짜** | `EXAM.EXAM_DATE` (검사일 기준) |
| **쿼리** | [select-monthly-vision-rates.sql](../../../backend/src/main/resources/sql/softcrm/consultation/select-monthly-vision-rates.sql) |

### 무엇으로 이루어지나 — 4단계 플래그

한 번의 검사(=`EXAM` 한 행)마다 아래 네 가지를 판정함.

| 플래그 | 뜻 | 판정 조건 |
|---|---|---|
| `examCount` | 검사함 | `EXAM` 행 존재 (`CANCEL_CD=''`) |
| `counsel` | **상담함** | `STOP_YN <> 'Y'` **그리고** 적절수술(`OPERATIONR`·`OPERATIONL`) 중 하나라도 입력됨 |
| `booked` | **수술 예약함** | 수술 예약(`RESERVE_FLAG='O'`, `STATE<>'C'`)이 존재 |
| `actual` | **실제 수술함** | `OPERATIONDATA`에 수술 기록 존재 |
| `od` | 원데이 | 그날 검사OP(`M`/`5`) 예약 존재 |

**`counsel`이 핵심임.** 검사만 하고 끝난 게 아니라 **의사가 수술 방법을 제시한 상태**를 뜻함.
중단(`STOP_YN='Y'`)이면 상담으로 안 침.

### 산출되는 값

| 컬럼 | 뜻 |
|---|---|
| `counselCount` | 상담한 사람 |
| `surgeryBookedCount` | 수술 예약한 사람 |
| `actualSurgeryCount` | 실제 수술한 사람 |
| `counselOneday` / `counselBookedOneday` | 원데이 상담 / 그중 예약 |
| `counselGeneral` / `counselBookedGeneral` | 일반 상담 / 그중 예약 |
| `examGeneral` / `bookedGeneral` | 일반 검사 / 그중 예약 |

**상담성공률 = `counselBooked` ÷ `counsel`** 을 전체 · 원데이 · 일반 3계열로 냄.

### ⚠️ 가장 큰 함정 — `booked`·`actual`에 기간 제한이 없음

```sql
LEFT JOIN (
    SELECT CUST_NUM, MIN(RESERVE_DATE) AS MIN_RSV_DATE
      FROM RESERVATION WITH(NOLOCK)
     WHERE RESERVE_FLAG = 'O' AND RESERVE_STATE <> 'C'
     GROUP BY CUST_NUM              -- ★ 날짜 조건 없음
) rs ON rs.CUST_NUM = E.CUST_NUM
```

**"이 검사 이후에 예약했는지"가 아니라 "언제든 수술 예약 이력이 있는지"** 를 봄.
`actual`(실제 수술)도 마찬가지로 `OPERATIONDATA` 전체를 봄.

즉 **2020년에 수술 예약한 이력이 있으면 2026년 검사도 "예약함"으로 잡힘.**
재방문 환자가 많은 달일수록 전환율이 높게 나옴. 해석할 때 감안할 것.

## 2. 백내장 — 예약률

| 항목 | 내용 |
|---|---|
| **테이블** | `RESERVATION`(백내장검사 `H`) + `CUSTOM` |
| **날짜** | `RESERVE_DATE` |
| **쿼리** | [select-monthly-cataract-rates.sql](../../../backend/src/main/resources/sql/softcrm/consultation/select-monthly-cataract-rates.sql) |

| 값 | 판정 |
|---|---|
| `examCount` | 백내장검사 예약 내원 고객 (`DISTINCT CUST_NUM`) |
| `surgeryBookedCount` | 그중 **백내장 수술 예약**(`FLAG='O'`, `JINRYO='4'`, `STATE<>'C'`) 있는 사람 |
| `stoppedCount` | 검안사 배정됨 + 상담사 `BS0808` = **중단** |

**예약률 = `surgeryBookedCount` ÷ `examCount`**

### ⚠️ 검사수 쿼리와 조건이 다름

| | 검사수([select-cataract-monthly.sql](../../../backend/src/main/resources/sql/softcrm/exam/select-cataract-monthly.sql)) | 예약률(이 쿼리) |
|---|---|---|
| 예약 상태 | `NOT IN ('C','Y')` — **미내원 제외** | `<> 'C'` — **미내원 포함** |
| 검안사 조건 | **있음** | 없음 |

**그래서 예약률의 분모(`examCount`)는 백내장 검사수와 다른 숫자임.**
`RESERVE_JINRYO='4'`(백내장 수술)도 여기서만 걸림 — 미지정 시 시력교정 수술예약이 섞임.

> 단위가 눈 → 사람으로 바뀐 뒤 **분모 재검토가 필요한 상태**임.

## 3. 중단률

| 항목 | 내용 |
|---|---|
| **정의** | 중단한 사람 ÷ 시력교정 검사자 |
| **중단 판정** | `EXAM.STOP_YN = 'Y'` |
| **분모** | `visionExam` (시력교정 검사자) |
| **화면** | `/stats/stop-rate` (2026-07-07 신규) |

> ⚠️ 분모인 `visionExam`이 바뀌면 중단률도 같이 움직임.
> 원데이 판정 변경 등 **검사자 정의를 손대면 반드시 함께 확인**할 것.

## 4. 중단 사유 — 7개 버킷

중단 건(`STOP_YN='Y'`)을 **상담사가 드롭다운에서 고른 정형 코드** `EXAM.CANCEL_CD`(char(3))로 분류함.
코드 마스터는 `CANCEL_CFG`.

| 버킷 | 라벨 | 코드 | 그룹 |
|---|---|---|---|
| `recommendX` | 불가-수술권유X | 121 · 305 | 수술 불가 |
| `lensImpossible` | 불가-렌즈삽입불가 | 122 · 306 · 399 | 수술 불가 |
| `keratoconus` | 불가-원추각막 | 124 · 125 · 308 · 309 | 수술 불가 |
| `avellino` | 불가-아벨리노 | 126 · 310 | 수술 불가 |
| `glaucoma` | 불가-녹내장 | 114 · 303 | **잠정 중단** |
| `visionChange` | 불가-시력변화 | 111 · 302 | **잠정 중단** |
| `other` | 기타 | 107 · 199 · 117 · 304 · 127 · 311 · 미지 코드 | **잠정 중단** |

**코드군이 두 벌임** — `1xx`(검사 중단) / `3xx`(같은 라벨 세트).
같은 사유가 두 코드로 들어오므로 **새 코드를 추가할 땐 짝이 있는지 확인**해야 함.

`117`·`304`(불가_백내장FU), `127`·`311`(불가_기타 각막병증)은 라벨이 `불가_`로 시작하지만
**검토 결과 기타(잠정 중단)로 귀속하기로 결정**했음(2026-07-15).

### ⚠️ 함정 두 가지

**① `ELSE`로 떨어지는 코드는 조용히 `other`가 됨**

운영에 새 `CANCEL_CD`가 생겨도 에러 없이 **기타 항목만 증가함.**
골든 대조에서 기타가 늘면 이걸 먼저 의심할 것.
검토를 마친 코드는 `ELSE`에 흘리지 말고 `WHEN`으로 명시해야
**"검토해서 기타로 정한 코드"와 "몰라서 샌 코드"가 구분됨.**

**② `CANCEL_CD`는 이름과 달리 취소 플래그가 아님**

이 쿼리에서는 **중단 사유 코드**로 쓰지만,
다른 쿼리들은 같은 컬럼을 **취소 판정**(`ISNULL(e.CANCEL_CD,'') = ''`)에 씀.
**한쪽 의미로만 알고 고치면 다른 쪽이 깨짐.**

## 남은 확인 사항

- **`booked`·`actual`의 기간 무제한 판정** — "이 검사에서 이어진 예약"으로 좁힐지 업무 판단 필요.
  좁히면 전환율이 낮아지지만 의미는 정확해짐.
- **백내장 예약률 분모** — 검사수(2026-07 = 56)와 다른 모집단을 씀. 단위 변경 후 재검토 대상.
- **중단률 분모** — `visionExam`이 중단·취소를 제외하지 않음([검사](../2-검사.md) §5-⑤).
