지표정의 6 — 외래

환자 흐름(예약 → 검사 → 전환율/중단율 → 수술 → 외래)의 마지막 단계. 무엇으로 이루어지고, 데이터를 어디서 가져오는지를 정리함.

1. 무엇으로 이루어지나 — 외래 진료구분

RESERVE_FLAG='F' 안에서 RESERVE_JINRYO로 세부 구분됨. 현재 집계는 이걸 구분하지 않고 전부 합산함.

외래의 83%가 수술 후 관리임. 수술후외래(2,114) + OP FU(755) = 2,869 / 3,445. 외래수는 사실상 수술 볼륨을 뒤따라가는 지표로 읽는 것이 맞음.

코드·명칭은 MEDICAL_SUB_CFG(RESERVE_FLAG='F')에서 옴. 세부 분해가 필요하면 아래 쿼리를 씀.

-- 외래 진료구분별 분해 (참고용, 현재 화면에는 없음)
SELECT ISNULL(r.RESERVE_JINRYO,'') AS jinryo, ms.SUB_NAME, COUNT(*) AS cnt
FROM RESERVATION r WITH(NOLOCK)
LEFT JOIN MEDICAL_SUB_CFG ms WITH(NOLOCK)
  ON ms.RESERVE_FLAG = 'F' AND ms.SUB_FLAG = ISNULL(r.RESERVE_JINRYO,'')
WHERE r.RESERVE_FLAG = 'F' AND r.RESERVE_STATE IN ('I','H')
  AND r.RESERVE_DATE >= :from AND r.RESERVE_DATE <= :to
GROUP BY ISNULL(r.RESERVE_JINRYO,''), ms.SUB_NAME
ORDER BY cnt DESC

2. 집계 쿼리

SELECT CAST(SUBSTRING(r.RESERVE_DATE, 1, 4) AS INT) AS yr,
       CAST(SUBSTRING(r.RESERVE_DATE, 6, 2) AS INT) AS mo,
       COUNT(*) AS cnt
FROM RESERVATION r WITH(NOLOCK)
WHERE r.RESERVE_DATE >= :from AND r.RESERVE_DATE <= :to
  AND r.RESERVE_FLAG = 'F'
  AND r.RESERVE_STATE IN ('I','H')
GROUP BY CAST(SUBSTRING(r.RESERVE_DATE, 1, 4) AS INT),
         CAST(SUBSTRING(r.RESERVE_DATE, 6, 2) AS INT)
ORDER BY yr, mo

조건이 세 줄뿐임. 다른 지표와 달리 테스트 고객 제외·담당자 조건 같은 것이 없음.

4. 알아둬야 할 함정

① 사람 수가 아니라 건수임

동일인이 여러 번 외래를 오면 각각 1건으로 잡힘. "외래 환자 수"로 읽으면 안 됨. 사람 수가 필요하면 COUNT(DISTINCT CUST_NUM)으로 별도 산출해야 함.

② RESERVE_JINRYO='3'(수술후망막)을 전역에서 빼지 말 것

2025-02에 레거시 5,389 vs DB 5,673으로 +284 차이가 났음. 그 달 RESERVE_JINRYO='3'이 294건이라 원인처럼 보이지만, 이 코드를 전역에서 제외하면 다른 월이 크게 틀어짐.

참고로 2026-06·07의 3(수술후망막)은 월 28~30건에 불과함. 2025-02가 유독 많았던 것이라 그 달만의 사정으로 보임. 2024~2025는 레거시 고정값을 쓰므로 화면 표시에는 영향이 없음. 전역 제외 규칙으로 만들지 말 것.

②-1 진료구분이 비어 있는 건이 월 40~50건 있음

RESERVE_JINRYO가 빈 값인 외래가 6월 53건 · 7월 39건임. 현재는 전부 외래수에 포함됨. 분해 리포트를 만들 때 "(미분류)" 항목이 생김는 점을 감안할 것.

③ 외래 예약이 검사자 집계에 섞여 들어감

외래(F) 예약으로 내원했는데 검사 기록(EXAM)이 만들어지는 경우가 있음. 이러면 시력교정 검사자로도 잡힘 — 2026년 6·7월 기준 월 3~4명.

자세한 내역과 대상자 명단은 시력교정-검사자-점검_2026-06~07.md §2 참조. 외래수 자체에는 영향이 없고, 검사자 수가 부풀려지는 방향임.

④ 백내장 외래는 별도 코드임

백내장 쪽 외래는 RESERVE_FLAG='Z'(백내장외래)로 따로 있음. 현재 외래수에는 포함되지 않음. 합산이 필요하면 별도 합의가 필요함.

남은 확인 사항

  • 백내장외래(Z) 포함 여부 — 업무 판단 필요. 현재 외래수에는 안 들어감.
  • 진료구분별 분해 화면 필요 여부 — 데이터는 있으나 현재 화면은 총합만 보여줌. 수술후외래·OP FU가 83%를 차지하므로, 나머지를 따로 보고 싶다면 분해가 의미 있음.
  • 미분류(빈 진료구분) 월 40~50건 — 입력 누락인지 의도된 것인지 확인 필요.
