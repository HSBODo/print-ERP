## 1. 먼저 알아야 할 것 — 데이터 소스가 다르다

이 화면만 **대시보드 DB(Postgres/MSSQL)가 아니라 레거시 홈페이지 데이터**를 본다.
**소스는 두 가지고, `LEGACY_DATASOURCE_URL` 접두사 하나로 갈린다**(`LegacyDialect`).

```
레거시 TBL_COUNSEL (CATEGORY='COUNSELONLINE')
   ├─ jdbc:sqlite:   → 로컬 스냅샷 파일  → legacyJdbcTemplate → 화면   (기본)
   └─ jdbc:mariadb:  → 운영 DB (SSH 터널) → legacyJdbcTemplate → 화면   (실시간)
```

| | A. 스냅샷 (기본) | B. 운영 DB 직결 (실시간) |
|---|---|---|
| 데이터 시점 | **2026-07-10 16:15:55 까지** | 실시간 |
| 필요한 것 | 없음(파일만) | SSH 터널 + 계정 2개 |
| 경고 배너 | **뜬다**(천장 초과 시) | 안 뜬다 · 대신 초록 "실시간" 표시 |
| 설정 | 2-2 A | 2-2 B |

- 스냅샷 위치: `c:/workspace/php_home/bnviit-homepage-admin-rebuild/.cache/legacy-consultations.sqlite`
- 상세 배경·함정은 `온라인예약-조회-가이드.md`(bnviit-homepage-admin-rebuild 리포 소유 · 이 리포에는 untracked) 참조 (이 작업의 근거 문서. 주장 8건 실측 검증 완료).

> ⚠️ **스냅샷일 때 조용한 실패 주의** — 조회 기간이 스냅샷을 넘으면 에러 없이 **건수가 모자라게** 나온다.
> 화면이 경고 배너를 띄우게 해뒀다(`lastRegDate` 비교). **이 동작을 지우지 말 것.**
> 실시간에서는 천장이 없어 같은 비교가 거짓 경고가 되므로, `live` 플래그로만 끈다 — 배너 자체를 지우면 안 된다.

> ⚠️ **같은 데이터인데 스키마가 다르다.** 캐시는 원본을 snake_case 로 **개명**해 적재했다:
> `TBL_COUNSEL`↔`consultations` · `C_NO`↔`legacy_no` · `M_NM`↔`name` · `DIVICE_TYPE`↔`device_type`(원본 오타).
> 그래서 SQL 을 방언별로 나눠 뒀다(`sql/reservation-list-homepage/{sqlite,mariadb}/`).
> **한쪽 SQL 을 다른 쪽에 그대로 쓰면 'no such column' 이 난다. 고칠 땐 양쪽을 같이 고칠 것** —
> 결과 별칭 계약(14개)이 어긋나면 한쪽 소스에서만 화면이 깨진다(테스트가 양쪽에 강제한다).

```properties
nexusUsername=<아이디>
nexusPassword=<비밀번호>
```

도커 빌드는 이 파일을 못 읽으므로 BuildKit secret 을 쓴다:

```bash
DOCKER_BUILDKIT=1 docker build \
  --secret id=nexus_id,env=NEXUS_USERNAME \
  --secret id=nexus_pw,env=NEXUS_PASSWORD \
  -t bviit-analytics:latest .
```

### 2-2. 레거시 소스 연결

`LEGACY_DATASOURCE_URL` 이 **비어 있으면 관련 빈이 아예 안 뜨고 이 API 만 503** 이다(앱 기동은 정상).
프로파일과 무관하게 이 값의 유무로만 켜진다. **접두사가 방언·드라이버·SQL 세트·실시간 여부를 모두 결정한다**
— 드라이버를 따로 지정할 필요가 없다(`legacy.datasource.driver-class-name` 은 URL 에서 파생).

#### A. 스냅샷 (기본 · 자격증명 불필요)

```bash
# backend/.env — 호스트에서 직접 실행(gradlew bootRun) 시
LEGACY_DATASOURCE_URL=jdbc:sqlite:c:/workspace/php_home/bnviit-homepage-admin-rebuild/.cache/legacy-consultations.sqlite?open_mode=1
```

`?open_mode=1` = SQLITE_OPEN_READONLY. Hikari read-only 설정과 짝이라 빼면 안 된다.

**도커**는 컨테이너가 호스트 경로를 못 보므로 `docker-compose.yml` 이 빈 값으로 덮어 기본 꺼짐이다.
쓰려면 `docker-compose.override.yml` 을 만든다(로컬 전용·gitignored, compose 가 자동 병합):

```yaml
services:
  analytics:
    environment:
      LEGACY_DATASOURCE_URL: "jdbc:sqlite:/app/legacy/legacy-consultations.sqlite?open_mode=1"
    volumes:
      - "c:/workspace/php_home/bnviit-homepage-admin-rebuild/.cache/legacy-consultations.sqlite:/app/legacy/legacy-consultations.sqlite:ro"
```

#### B. 운영 DB 직결 (실시간 · 2026-07-15 실증 완료)

경로는 `온라인예약-조회-가이드.md`(bnviit-homepage-admin-rebuild 리포 소유 · 이 리포에는 untracked) §1-C 와 같다. **비밀번호는 리포에 없다 — 사용자에게 요청할 것**
(SSH 와 DB 가 **서로 다른 비번**이다. 같은 값으로 넣으면 `All configured authentication methods failed` 가 난다).

```
SSH  110.45.179.230:2200  bseye_kr
  └→ DB 192.168.200.32:3306  bseyecom_db / bseyecom_user  (MariaDB 10.3, MyISAM/utf8mb3)
```

컨테이너는 사설망의 DB 에 직접 못 간다 → **SSH 터널 사이드카**를 둔다. 자격증명은 `backend/.env`(gitignored):

```bash
LEGACY_SSH_PASSWORD=<SSH 비번>
LEGACY_DB_PASSWORD=<DB 비번>
```

```yaml
# docker-compose.override.yml (로컬 전용·gitignored)
services:
  legacy-tunnel:
    image: alpine:3.20
    environment:
      SSH_PASS: ${LEGACY_SSH_PASSWORD:?}
    command:
      - sh
      - -c
      - |
        apk add --no-cache openssh-client sshpass >/dev/null 2>&1
        exec sshpass -p "$$SSH_PASS" ssh -N -o StrictHostKeyChecking=no \
          -o UserKnownHostsFile=/dev/null -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 \
          -L 0.0.0.0:3306:192.168.200.32:3306 -p 2200 bseye_kr@110.45.179.230
    healthcheck:
      test: ["CMD-SHELL", "nc -z 127.0.0.1 3306 || exit 1"]
      interval: 10s
      start_period: 20s
  analytics:
    depends_on:
      legacy-tunnel: { condition: service_healthy }
    environment:
      LEGACY_DATASOURCE_URL: "jdbc:mariadb://legacy-tunnel:3306/bseyecom_db"
      LEGACY_DATASOURCE_USERNAME: bseyecom_user
      LEGACY_DATASOURCE_PASSWORD: ${LEGACY_DB_PASSWORD:?}
```

> 🚨 **터널을 호스트 포트로 노출하지 말 것**(`ports:` 금지). 위 `0.0.0.0` 은 **컨테이너 안**이라
> compose 내부망까지만 열린다. 호스트에 열면 같은 네트워크의 누구나 인증 없이 운영 DB 앞까지 도달한다.

> ⚠️ **fail2ban** — SSH 인증을 몇 번 틀리면 소스 IP 가 수십 분 차단된다. 비번을 바꿔가며 재시도하지 말 것.
> 차단되면 TCP 연결부터 실패하므로 인증 거부(`authentication methods failed`)와 증상이 다르다.

> ⚠️ **H2 콘솔이 켜져 있으면 레거시 DataSource 도 목록에 올라온다**(로그에 URL 이 찍힌다).
> 실시간 + `APP_H2_CONSOLE_ENABLED=true` 조합을 **운영에 올리지 말 것.**

## 3. ⚠️ DefaultDataSourceConfig — 지우지 말 것

`common/config/DefaultDataSourceConfig.java` 는 **버그 수정**이다. 없으면 H2 프로파일에서 기동이 깨진다.

- 기존엔 H2(프로파일 미지정)에서 Spring Boot 의 `DataSourceAutoConfiguration` 이 primary DataSource 를 만들어줬다.
- 그 auto-config 는 `@ConditionalOnMissingBean(DataSource.class)` — **DataSource 빈이 하나라도 생기면 통째로 물러난다.**
- `LegacyDataSourceConfig` 가 켜지자 SQLite 가 유일한 DataSource 가 되어 JPA 가 그걸 집어들고
  `Unable to determine Dialect for SQLite 3.47` 로 기동 실패했다.
- 그래서 다른 두 프로파일(`mssql`/`postgres-mart`)과 동일하게 primary 를 명시했다.

## 4. 레거시와 다르게 만든 부분 (의도적)

| 항목 | 결정 |
|---|---|
| 삭제·체크박스 | **제외** — 조회 전용. 쓰기 액션은 옮기지 않았다 |
| CSV 내보내기 | **제공** — 읽기 액션이라 다른 리스트 화면(검사자·수술자·예약자)과 동일하게 둔다. 개인정보가 원문으로 나가는 점 유의 |
| 검색 | 이름·**휴대폰번호** 통합 단일 입력. 레거시는 휴대폰 검색이 안 돼 운영 불편이 있었다 |
| 개인정보 | **원문 그대로** 표시(레거시 화면과 동일). 마스킹 안 함 |
| 스냅샷 경고 배너 | 신규 추가 — 레거시엔 없다. 실시간 소스면 초록 "실시간 · 마지막 등록건" 표시로 대체 |
| 필터 UI | 레거시 4블록 폼(라디오) 대신 **대시보드 리스트 화면 공통 툴바**(단일 행·세그먼트 버튼) |
| 필터 적용 시점 | 구분·예약구분·검색은 **즉시 반영**(클라이언트 필터라 서버 왕복 불필요). `조회` 는 등록일 재조회 전용 |

레거시 동작을 **그대로 따른** 부분(바꾸면 건수가 틀어진다):

- `del_tf='N'` 하드코딩 — 삭제건(281건)은 조회 대상 아님
- `ORDER BY legacy_no DESC` — 등록일이 아니라 PK 역순
- No 는 **총건수에서 1씩 감소**하는 표시용 번호(저장값 아님, 식별자는 `legacyNo`)
- `진료구분=1`(59건)은 레거시에도 라벨이 없어 **빈칸**

### 알아둘 것

- **네이버 값은 기존 종합의 NAVER 집계와 일부러 다르다.** RSS 는 취소를 빼고 정크필터를 안 쓴다.
  두 화면(월간 레포트 / 예약통계_시력교정)이 같은 숫자를 말하게 하는 게 이번 정의의 전제다. 맞추려 하지 말 것.
- **카카오는 원래 의도적으로 빠져 있었다.** 사유는 "레거시 RSS 가 월마다 포함/미포함이 들쭉날쭉"이었고,
  2026-01 부터는 마트가 직접 계산하므로 포함한다. 영향은 월 9~16건(1~3%).
- **백내장은 원래도 안 들어왔다.** 종합/네이버는 `RESERVE_FLAG='M'`(시력교정)으로 이미 걸러진다.

  판정은 소스와 무관하게 같다(`coverageMonth`): **말일까지 담긴 달만 인정**한다.
  스냅샷이 7/10 까지면 7월은 null(선 끊김). 실시간이어도 오늘이 7/15 면 7월은 아직 안 끝나 마찬가지로 null 이다.
- **차트 라벨** `온라인 예약 (네이버·카카오·홈페이지)` 은 2026-01 부터 사실이 된다. 그 이전 구간(24·25)엔
