# print-ERP Bare-Minimum MVP 계획

> **작성일**: 2026-11-05
> **포지션**: 1인 개발자, AI 코딩 도구 보조
> **전제**: [`DEVELOPMENT_PLAN.md`](./DEVELOPMENT_PLAN.md) 의 전체 전략 중 **최소 실행 범위**만 추려냄
> **가치 명제**: "영업부가 수주를 한 번 등록하면, 공정 담당자가 자기 공정 목록에서 실적만 입력한다. 끝."

## 1. 문제 정의 (사용설명서 §2 기반)

현재 엑셀 운영의 **단일 최대 고통**은 사용설명서 §2.3에 명시된:

> 검토후 해당열을 다시 복사하여 **작업현황, 인쇄, 드라이(논솔), 티다이(외주), 슬릿터(상품), 가공(외주) 시트의 제일 하단에 붙여넣기**

**수주 1건당 6개 시트 수기 복사**. 이 하나만 제거해도 핵심 가치 전달.

## 2. 범위 — 극한의 단순화

### ✅ 포함 (이것만)

| 기능 | 설명 |
|---|---|
| 로그인·계정관리 | 템플릿 그대로 재활용 (ROLE 2개: ADMIN·STAFF) |
| 수주 등록 | 단일 폼 — 최소 필드만 |
| 수주 목록 | 테이블 + 간단 필터(기간·고객) |
| 수주 저장 시 자동 WorkOrder 생성 | 선택된 공정 enum 수만큼 자동 생성 |
| 공정 큐 | 단일 화면 — 탭 전환으로 5개 공정 노출 |
| 실적 입력 | 투입량·생산량·비고 (3필드) |
| 완료 체크 | 단순 토글 (상태머신 X) |
| 배포 | EC2 1대 + Docker + HTTPS + 일 1회 DB 백업 |

### ❌ 제외 (전부 엑셀 유지)

**기능 제외**
- 마스터 CRUD (고객·외주처·제품) → **수주 폼에서 자유입력** (중복 방지는 자동완성만)
- 원장 제품마스터 이관
- 과거 수주 이관 (신규만 웹에서)
- PDF 출력 (브라우저 인쇄로 대체)
- 재고 (원단·동판·로라·인쇄물재고·창고출고)
- 설비 (압동로라 이력·연마)
- 품질체크
- 차량배차
- 작업현황 대시보드
- 월말실적보고서
- 외주처 포털 (외주 담당자 접근 불가, 사내 대리 입력)
- 모바일 반응형 (데스크톱만, 태블릿 가로모드만 지원)
- 실시간 알림

**모델 단순화**
- 공정 enum 13개 → **5개로 축소** (`PRINT`, `LAMINATION`, `DRY`, `SLITTER`, `OTHER`)
- 당사/외주 분리 트래킹 → `isOutsourced` 불리언 1개
- 상태 머신 → 단순 `completed` 플래그
- 수율·불량·근무일수·WIP → 전부 미구현

## 3. 데이터 모델 (4개 테이블)

```sql
users           -- 템플릿 유지
orders
  · id, lot_no, customer_name, product_code, product_name,
    quantity, order_date, due_date, process_route text[],
    remarks, created_at, created_by
work_orders
  · id, order_id, process (enum: PRINT/LAMINATION/DRY/SLITTER/OTHER),
    is_outsourced bool, vendor_name,
    input_qty, output_qty, remarks,
    completed bool, completed_at
audit_log       -- 최소 (생성/수정만)
```

- Flyway 마이그레이션 **2~3개**로 종료.
- 과거 데이터는 적재하지 않음. 엑셀을 그대로 조회용으로 유지.

## 8. 운영 모델 (계약서에 명시)

### 웹 담당 범위
- 신규 수주 등록
- 공정 담당자 실적 입력 (투입·생산·완료)
- 최근 수주 조회·필터

### 엑셀 담당 범위 (당분간 유지)
- 원장 (제품마스터) 조회·업데이트
- 재고·설비·품질·배차 전부
- 월말실적보고서
- 과거 3년 수주 조회

### 연결 지점
- 신규 수주를 웹에 입력하면 엑셀 `수주내역` 시트에는 **더 이상 수기 복사 안 함**
- 월말 집계 필요 시 웹에서 수주 목록 CSV 다운로드 → 엑셀 월말 보고서로 복사(선택)

## 13. MVP 이후 확장 로드맵 (판매 포인트)
