# 지표정의 — 환자 흐름별

환자가 병원을 거치는 순서대로 지표를 정리한 문서 묶음이다.
각 문서는 **그 지표가 무엇으로 이루어지고, 데이터를 어디서 가져오는지**를 표로 보여준다.

```
예약  →  검사  →  전환율 / 중단율  →  수술  →  외래
```

| # | 문서 | 무엇을 세나 | 소스 테이블 | 세는 단위 |
|---|---|---|---|---|
| 1 | [예약](1-예약.md) | 검사받으러 오기로 한 사람 | `RESERVATION` (`M`) | 예약 건 |
| 2 | [검사](2-검사.md) | 실제로 검사받은 사람 | `EXAM` · `RESERVATION`(`H`) | 사람 |
| 3 | [전환율·중단율](3-전환율-중단율.md) | 수술로 이어진 비율 / 멈춘 비율 | `EXAM` + 수술 예약·기록 | 비율 |
| 4 | [수술](4-수술.md) | 실제로 수술받은 사람 | `OPERATIONDATA` · `Cataract_Operationdata` · `RE_OPERATION` | 사람 / 눈 / 건 |
| 5 | [외래](5-외래.md) | 수술 후 경과 보러 온 사람 | `RESERVATION` (`F`) | 건 |

## 먼저 알아둘 것

**집계 단위가 지표마다 다르다.** 단순히 더하면 안 된다.

| 단위 | 해당 지표 |
|---|---|
| **사람** | 시력교정검사 · 드림렌즈검사 · 백내장검사 · 시력교정수술 |
| **눈** (좌/우 각각) | 백내장수술 |
| **건** | 예약 · 외래 · 재수술 |

**날짜 기준도 다르다.**

| 기준 | 해당 지표 |
|---|---|
| 실제 실행일 | 검사(`EXAM_DATE`) · 수술(`OPERATION_DATE`) |
| 예약일 | 백내장검사 · 외래(`RESERVE_DATE`) |
| **등록일** | **예약**(`InsertedDateTime`) — 예약일이 아니다 |

**2024~2025는 레거시 확정값을 고정**해 쓰는 지표가 있다(예약·외래·백내장검사수).
DB 재집계로 맞추려 하지 말 것.
