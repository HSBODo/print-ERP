# 검사 리스트 컬럼 정의서 (시력교정 · 백내장)

> SoftCRM **검사자 리스트** 계열 엑셀 출력(75/78컬럼) ↔ java_dashboard API 매핑 문서.
> **시력교정판(본문) + 백내장판(문서 후반 【백내장판】)** 두 벌을 한 문서에 담는다.  
> DB 기준: MSSQL(SOFTCRM), READ-ONLY, 대용량 테이블 `WITH(NOLOCK)` + 날짜 범위 필수  
> 최종 갱신: 2026-06-16

> **개발자용 요약**: 화면에 실제로 뜨는 컬럼은 [화면 표시 컬럼](#화면-표시-컬럼-실제-화면-기준)(51열), 실제 실행 SQL 전문은 [호출 쿼리문](#호출-쿼리문-실제-실행-sql) 참조. 아래 [컬럼 매핑](#컬럼-매핑)은 원본 엑셀 78열 기준 추적표.

## 요약

| 항목 | 내용 |
|---|---|
| 화면명 | 검사자 리스트 (상담사별) |
| 원본 계열 | `FrmCounselExamList` 구 25컬럼 + 확장 75/78컬럼 SQL |
| 주 데이터 | `EXAM` + `CUSTOM` |
| 기간 기준 | `EXAM.EXAM_DATE` |
| 현재 API | `GET /api/exam-list?from=YYYY-MM-DD&to=YYYY-MM-DD` |
| 현재 구현 | 시력교정 `EXAM` 분기 중심. 백내장 본분기 `UNION` 미구현 |
| 프론트 표시 | 검사정보 측정값 제외, 비측정 47필드 표시 |

> **주의:** 이 화면의 “검사자”는 사람 배정 현황이 아님.  
> 고객별 검사자료 + 예약 + 상담 + 수술 관련 마스터 리스트에 가까움. `uASSIGN1` 검사배정현황과 혼동 금지.

## 출력 기준

java_dashboard 검사자 리스트 API 기준:

- 기간 내 `EXAM.EXAM_DATE` 행 조회
- 상담사/상담의 제한 없이 전체 조회
- 진료구분/예약 부가정보는 검사일과 같은 날의 검사예약 기준
  - `RESERVE_FLAG='M'`
  - `RESERVE_DATE = EXAM.EXAM_DATE`
  - `RESERVE_STATE IN ('I','H')`
- 검사분류는 별도 파생값
  - 같은 검사일에 렌즈센터 예약 `D`만 있고 검사예약 `M`이 없으면 `드림렌즈`
  - 그 외 `시력교정`
- 테스트 데이터 제외
  - 고객명에 `테스트`, `test`, `TEST` 포함 시 제외
  - 검사메모/예약번호의 `test` 문구는 제외 기준으로 사용하지 않음
  - `장용테스트`, `모노비전TEST` 같은 정상 임상 메모 오탐 방지 목적
- 백내장 검사 그림자 행 제외
  - 같은 고객/검사일에 `Cataract_Exam` 본행 존재
  - 일반 `EXAM.RIGHT01~RIGHT30/LEFT01~LEFT30` 측정값 전부 공백
  - 위 조건이면 시력교정 검사자 리스트에서 제외
- 모든 응답 필드는 문자열 보장
  - 프론트 Zod 스키마가 `z.string()` 기준이라 `null` 금지

## 호출 쿼리문 (실제 실행 SQL)

> 출처: [ExamListRepository.java](../../backend/src/main/java/com/bviit/analytics/exam/repository/ExamListRepository.java) `findExamList(from, to)`.
> 엔드포인트: `GET /api/exam-list?from=YYYY-MM-DD&to=YYYY-MM-DD` (Profile `mssql`).  
> 파라미터: `:from`, `:to` = 검사일 범위(`EXAM.EXAM_DATE`, char(10)).  
> `NamedParameterJdbcTemplate.queryForList` → `List<Map<String,Object>>` 그대로 응답(DTO 없음, alias=JSON 키).

```sql
SELECT
  ISNULL(LTRIM(RTRIM(cu.CUST_NUM)), '')        AS chartNo,
  ISNULL(cu.CUST_NAME, '')                     AS name,
  ISNULL(cu.CUST_ENAME, '')                    AS nameEng,
  ISNULL(e.EXAM_DATE, '')                      AS examDate,
  ISNULL(
    NULLIF(LTRIM(RTRIM(ms.SUB_NAME)), ''),
    CASE
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='1' THEN '검사'
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='5' THEN '검사OP'
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='4' THEN 'DNA검사'
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='2' THEN '재검사'
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='6' THEN '당일재검사'
      WHEN ISNULL(rsv.RESERVE_JINRYO,'')='7' THEN '검사OP(Re)'
      ELSE ISNULL(rsv.RESERVE_JINRYO, '')
    END
  )                                             AS examType,
  CASE WHEN visit.hasDreamlens = 1 AND visit.hasMedical = 0 THEN '드림렌즈' ELSE '시력교정' END AS examCategory,
  CASE WHEN ISNULL(cu.FIRST_DAY, '') >= :from AND ISNULL(cu.FIRST_DAY, '') <= :to
       THEN '신환' ELSE '구환' END             AS patientType,
  ISNULL(rsvReg.regDate, '')                   AS examRegDate,
  ISNULL(e.EXAM_MEMO, '')                      AS examMemo,
  ISNULL(e.OP_ESTIMATE, '')                    AS estimate,
  ISNULL(e.ExamPercent, '')                    AS surgeryRate,
  ISNULL(rsv.START_TIME, '')                   AS examTime,
  ISNULL(e.OPERATIONR, '')                     AS recommendedR,
  ISNULL(e.OPERATIONL, '')                     AS recommendedL,
  ISNULL(opReg.regDate, '')                    AS surgeryRegDate,
  ISNULL(opRsv.RESERVE_DATE, '')               AS surgeryReserveDate,
  ISNULL(op.OPERATION_DATE, '')                AS surgeryDate,
  ISNULL(op.OPERATIONR, '')                    AS surgeryR,
  ISNULL(op.OPERATIONL, '')                    AS surgeryL,
  ISNULL(os.EMP_NAME, '')                      AS surgeon,
  ISNULL(REPLACE(CONVERT(varchar(30), CONVERT(money, NULLIF(pay.RECEIPT, 0)), 1), '.00', ''), '') AS payment,
  ISNULL(ec.EMP_NAME, '')                      AS counselor,
  ISNULL(ed.EMP_NAME, '')                      AS doctor,
  ''                                           AS jumin,              -- PII: 복호화/마스킹 필요
  ISNULL(cu.BIRTH_DAY, '')                     AS birth,
  CASE WHEN cu.LUNAR_YN = 'Y' THEN '음' ELSE '양' END AS lunar,
  ISNULL(cu.CALL_NUM1, '')                     AS phone1,
  ISNULL(cu.CALL_NUM2, '')                     AS phone2,
  ISNULL(cu.EMAIL, '')                         AS email,
  ISNULL(LTRIM(RTRIM(cu.ZIP_CODE)), '')        AS zip,
  ISNULL(cu.ADDR1, '')                         AS addr1,
  ISNULL(cu.ADDR2, '')                         AS addr2,
  ISNULL(cu.ETC, '')                           AS memo,
  ISNULL(e.STOP_YN, '')                        AS examStop,
  ISNULL(e.OP_POSSIBLE_YN, '')                 AS opImpossible,
  ISNULL(rsv.RESERVE_PATH, '')                 AS route,
  ISNULL(motive.section, '')                   AS section,
  ISNULL(motive.motiveL, '')                   AS motiveL,
  ISNULL(motive.motiveM, '')                   AS motiveM,
  ISNULL(motive.motiveS, '')                   AS motiveS,
  ISNULL(motive.motiveMemo, '')                AS motiveMemo,
  ISNULL(eo.EMP_NAME, '')                      AS optometrist,
  ISNULL(LTRIM(RTRIM(e.CANCEL_CD)), '')        AS cancelCode,
  ISNULL(NULLIF(e.CANCEL_REASON, ''), ISNULL(cc.CANCEL_REASON, '')) AS cancelMemo,
  ISNULL(cu.LEVEL, '')                         AS grade,
  ISNULL(cu.JOB, '')                           AS job,
  ISNULL(cu.LAST_DAY, '')                      AS lastVisit,
  ISNULL(ins.EtcCodNam, '')                    AS insurance,
  ISNULL(nation.Nation_CodeName, '')           AS nationality
FROM EXAM e WITH(NOLOCK)
JOIN CUSTOM cu WITH(NOLOCK)              ON e.CUST_NUM = cu.CUST_NUM
LEFT JOIN OPERATIONDATA op WITH(NOLOCK)  ON e.CUST_NUM = op.CUST_NUM
LEFT JOIN EMPLOYEE ec WITH(NOLOCK)       ON cu.MY_COUNSELOR   = ec.EMP_NUM
LEFT JOIN EMPLOYEE ed WITH(NOLOCK)       ON cu.MY_DOCTOR      = ed.EMP_NUM
LEFT JOIN EMPLOYEE eo WITH(NOLOCK)       ON cu.MY_OPTOMETRIST = eo.EMP_NUM
LEFT JOIN EMPLOYEE os WITH(NOLOCK)       ON op.OPERATION_DOC  = os.EMP_NUM
LEFT JOIN CANCEL_CFG cc WITH(NOLOCK)     ON e.CANCEL_CD       = cc.CANCEL_CD
LEFT JOIN NationCustom_CFG nation WITH(NOLOCK) ON cu.Nation_code = nation.Code
LEFT JOIN EtcCfg ins WITH(NOLOCK)
  ON ins.EtcBseCod = 'InsuranceCfg'
 AND ins.EtcCod = cu.InsuranceCode
OUTER APPLY (
  SELECT
    CASE WHEN EXISTS (
      SELECT 1 FROM RESERVATION rd WITH(NOLOCK)
      WHERE rd.CUST_NUM = e.CUST_NUM
        AND rd.RESERVE_DATE = e.EXAM_DATE
        AND rd.RESERVE_STATE IN ('I','H')
        AND rd.RESERVE_FLAG = 'D'
    ) THEN 1 ELSE 0 END AS hasDreamlens,
    CASE WHEN EXISTS (
      SELECT 1 FROM RESERVATION rm WITH(NOLOCK)
      WHERE rm.CUST_NUM = e.CUST_NUM
        AND rm.RESERVE_DATE = e.EXAM_DATE
        AND rm.RESERVE_STATE IN ('I','H')
        AND rm.RESERVE_FLAG = 'M'
    ) THEN 1 ELSE 0 END AS hasMedical
) visit
OUTER APPLY (
  SELECT TOP 1 r.*
  FROM RESERVATION r WITH(NOLOCK)
  WHERE r.CUST_NUM = e.CUST_NUM
    AND r.RESERVE_DATE = e.EXAM_DATE
    AND r.RESERVE_STATE IN ('I','H')
    AND r.RESERVE_FLAG = 'M'
  ORDER BY r.RESERVE_NUM DESC
) rsv
LEFT JOIN MEDICAL_SUB_CFG ms WITH(NOLOCK)
  ON ms.RESERVE_FLAG = rsv.RESERVE_FLAG
 AND ms.SUB_FLAG = ISNULL(rsv.RESERVE_JINRYO, '')
OUTER APPLY (
  SELECT CASE WHEN LEN(LTRIM(RTRIM(ISNULL(rsv.RESERVE_NUM, '')))) >= 6
              THEN '20' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 1, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 3, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 5, 2)
              ELSE '' END AS regDate
) rsvReg
OUTER APPLY (
  SELECT TOP 1 f.*
  FROM RESERVATION f WITH(NOLOCK)
  WHERE f.CUST_NUM = e.CUST_NUM AND f.RESERVE_FLAG = 'O' AND f.RESERVE_STATE <> 'C'
  ORDER BY f.RESERVE_NUM DESC
) opRsv
OUTER APPLY (
  SELECT CASE WHEN LEN(LTRIM(RTRIM(ISNULL(opRsv.RESERVE_NUM, '')))) >= 6
              THEN '20' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 1, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 3, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 5, 2)
              ELSE '' END AS regDate
) opReg
OUTER APPLY (
  SELECT TOP 1
    ISNULL(m2.category01_name, '') AS motiveL,
    ISNULL(m2.category02_name, '') AS motiveM,
    ISNULL(m2.category03_name, '') AS motiveS,
    ISNULL(NULLIF(m1.comments, ''), ISNULL(m2.name, '')) AS motiveMemo,
    ISNULL(CONVERT(varchar(10), m2.[section]), '') AS section
  FROM MOTIVE_NEW02 m2 WITH(NOLOCK)
  LEFT JOIN MOTIVE_NEW01 m1 WITH(NOLOCK) ON m2.fkey = m1.pkey
  WHERE m2.cust_num = e.CUST_NUM AND m2.Idx = '1'
  ORDER BY m2.pkey DESC
) motive
LEFT JOIN (
  SELECT TMP.PRC_CUSNUM, SUM(TMP.RECEIPT) AS RECEIPT
  FROM (
    SELECT A.CUST_NUM AS PRC_CUSNUM,
           SUM(ISNULL(A.COST_PRICE, 0)) AS RECEIPT
    FROM COSTPRICE A WITH(NOLOCK)
    LEFT JOIN (
      SELECT CstCusNum, CstSeq
      FROM CSTPRCSUB WITH(NOLOCK)
      GROUP BY CstCusNum, CstSeq
    ) B ON A.CUST_NUM = B.CstCusNum AND A.SEQ = B.CstSeq
    LEFT JOIN (
      SELECT PrcCusNum, PrcSeq
      FROM PRCITMLST WITH(NOLOCK)
      GROUP BY PrcCusNum, PrcSeq
    ) C ON A.CUST_NUM = C.PrcCusNum AND A.SEQ = C.PrcSeq
    WHERE B.CstCusNum IS NULL
      AND C.PrcCusNum IS NULL
      AND A.COST_FLAG IN ('O','I','H')
      AND UPPER(ISNULL(A.PayStt, '')) <> 'A'
    GROUP BY A.CUST_NUM

    UNION ALL

    SELECT B.CstCusNum AS PRC_CUSNUM,
           SUM(ISNULL(B.CstPrc, 0)) AS RECEIPT
    FROM COSTPRICE A WITH(NOLOCK)
    JOIN CSTPRCSUB B WITH(NOLOCK)
      ON A.CUST_NUM = B.CstCusNum
     AND A.SEQ = B.CstSeq
     AND A.COST_FLAG IN ('O','I','H')
     AND B.CstCnlYnN = 'N'
     AND B.CstPayTyp = 'N'
    LEFT JOIN PRCITMLST C WITH(NOLOCK)
      ON B.CstCusNum = C.PrcCusNum
     AND B.CstSeq = C.PrcSeq
    WHERE C.PrcCusNum IS NULL
      AND UPPER(ISNULL(A.PayStt, '')) <> 'A'
    GROUP BY B.CstCusNum

    UNION ALL

    SELECT T2.CUST_NUM AS PRC_CUSNUM,
           SUM(CASE D.PrcCnlYnN WHEN 'Y' THEN 0 ELSE ISNULL(D.PrcDtlPrc, 0) END) AS RECEIPT
    FROM (
      SELECT DISTINCT A.CUST_NUM, A.SEQ
      FROM COSTPRICE A WITH(NOLOCK)
      WHERE ISNULL(A.COST_FLAG, '') = ''
        AND UPPER(ISNULL(A.PayStt, '')) <> 'A'
    ) T2
    JOIN PRCITMLST C WITH(NOLOCK)
      ON T2.CUST_NUM = C.PrcCusNum
     AND T2.SEQ = C.PrcSeq
     AND C.PrcCod IN ('O','I','H')
    JOIN PrcItmDtl D WITH(NOLOCK)
      ON T2.CUST_NUM = D.PrcCusNum
     AND T2.SEQ = D.PrcSeq
     AND D.PrcCod IN ('O','I','H')
    GROUP BY T2.CUST_NUM
  ) TMP
  GROUP BY TMP.PRC_CUSNUM
) pay ON e.CUST_NUM = pay.PRC_CUSNUM
     AND e.CUST_NUM <> '9999999999999'
WHERE e.EXAM_DATE >= :from AND e.EXAM_DATE <= :to
  AND NOT (
    ISNULL(cu.CUST_NAME, '') LIKE N'%테스트%'
    OR LOWER(ISNULL(cu.CUST_NAME, '')) LIKE '%test%'
  )
  AND NOT (
    EXISTS (
      SELECT 1
      FROM Cataract_Exam ce WITH(NOLOCK)
      WHERE ce.CUST_NUM = e.CUST_NUM
        AND ce.EXAM_DATE = e.EXAM_DATE
    )
    AND NULLIF(LTRIM(RTRIM(ISNULL(e.RIGHT01, ''))), '') IS NULL
    AND NULLIF(LTRIM(RTRIM(ISNULL(e.LEFT01, ''))), '') IS NULL
    AND NULLIF(LTRIM(RTRIM(ISNULL(e.RIGHT02, ''))), '') IS NULL
```

## 데이터 소스

### 원본 기본 구조

```sql
FROM EXAM A
  INNER JOIN CUSTOM B        ON A.CUST_NUM = B.CUST_NUM
  LEFT  JOIN OPERATIONDATA C ON A.CUST_NUM = C.CUST_NUM
  LEFT  JOIN EMPLOYEE D      ON B.MY_COUNSELOR   = D.EMP_NUM
  LEFT  JOIN EMPLOYEE E      ON B.MY_DOCTOR      = E.EMP_NUM
WHERE A.EXAM_DATE BETWEEN @start AND @end
  AND (B.MY_DOCTOR = @doc OR @doc = '-1')
  AND B.MY_COUNSELOR = @userId
```

원본은 상담사 본인 데이터 중심. 대시보드는 전체 현황 목적이라 상담사/상담의 조건 제거함.

### 확장 SQL 추가 조인

- 검사예약: 검사일과 같은 날의 최신 `RESERVATION.RESERVE_NUM`
  - `RESERVE_FLAG='M'`
  - `RESERVE_DATE = EXAM.EXAM_DATE`
  - `RESERVE_STATE IN ('I','H')`
  - `RESERVE_STATE<>'C'`
- 수술예약: 고객별 최신 `RESERVATION.RESERVE_NUM`
  - `RESERVE_FLAG='O'`
  - `RESERVE_STATE<>'C'`
- 진료구분: `MEDICAL_SUB_CFG.SUB_NAME`
  - `RESERVE_FLAG + RESERVE_JINRYO` 매핑
- 수납금액: `COSTPRICE`/`CSTPRCSUB`/`PRCITMLST`/`PrcItmDtl` 집계 `RECEIPT`
- 내원동기: `MOTIVE_NEW02` + `MOTIVE_NEW01`
- 보험사: `EtcCfg`
- 국적: `NationCustom_CFG`

### 백내장 분기

원본 계열은 수술구분에 따라 시력교정/백내장 `UNION` 가능.

| 시력교정 | 백내장 |
|---|---|
| `EXAM` | `Cataract_Exam` |
| `OPERATIONDATA` | `Cataract_Operationdata` |
| `OP_POSSIBLE_YN` | `Impossible` |

현재 API는 시력교정 `EXAM` 중심. 단, 백내장 본행이 있는 일반 `EXAM` 빈 그림자 행은 제외함.

### 호출 쿼리문 (실제 실행 SQL)

> 출처: [CataractExamListRepository.java](../../backend/src/main/java/com/bviit/analytics/exam/repository/CataractExamListRepository.java) `findCataractExamList(from, to)`.
> 엔드포인트: `GET /api/cataract-exam-list?from=YYYY-MM-DD&to=YYYY-MM-DD` (Profile `mssql`).  
> 파라미터: `:from`, `:to` = 검사일 범위(`Cataract_Exam.EXAM_DATE`, char(10)).  
> 응답: `List<Map<String,Object>>`(DTO 없음, alias=JSON 키). 예약 조인은 **`RESERVE_FLAG='H'`**(백내장 검사예약) — 시력교정 `'M'`과 다름.

```sql
SELECT
  ISNULL(LTRIM(RTRIM(cu.CUST_NUM)), '')        AS chartNo,
  ISNULL(cu.CUST_NAME, '')                     AS name,
  ISNULL(cu.CUST_ENAME, '')                    AS nameEng,
  ISNULL(ce.EXAM_DATE, '')                     AS examDate,
  ISNULL(
    NULLIF(LTRIM(RTRIM(ms.SUB_NAME)), ''),
    CASE WHEN ISNULL(LTRIM(RTRIM(rsv.RESERVE_FLAG)),'') = 'H' THEN '백내장검사' ELSE '' END
  )                                            AS examType,
  ISNULL(rsvReg.regDate, '')                   AS examRegDate,
  '백내장'                                      AS examCategory,
  CASE WHEN ISNULL(cu.FIRST_DAY, '') >= :from AND ISNULL(cu.FIRST_DAY, '') <= :to
       THEN '신환' ELSE '구환' END             AS patientType,
  ISNULL(ce.EXAM_MEMO, '')                     AS examMemo,
  LTRIM(RTRIM(
    CASE
      WHEN ISNULL(NULLIF(LTRIM(RTRIM(ce.OP_ESTIMATE_R)),'0'),'') <> ''
       AND ISNULL(NULLIF(LTRIM(RTRIM(ce.OP_ESTIMATE_L)),'0'),'') <> ''
      THEN 'R ' + LTRIM(RTRIM(ce.OP_ESTIMATE_R)) + ' / L ' + LTRIM(RTRIM(ce.OP_ESTIMATE_L))
      WHEN ISNULL(NULLIF(LTRIM(RTRIM(ce.OP_ESTIMATE_R)),'0'),'') <> '' THEN LTRIM(RTRIM(ce.OP_ESTIMATE_R))
      WHEN ISNULL(NULLIF(LTRIM(RTRIM(ce.OP_ESTIMATE_L)),'0'),'') <> '' THEN LTRIM(RTRIM(ce.OP_ESTIMATE_L))
      ELSE '' END
  ))                                           AS estimate,
  ISNULL(ce.ExamPercent, '')                   AS surgeryRate,
  ISNULL(rsv.START_TIME, '')                   AS examTime,
  ISNULL(ce.OPERATIONR, '')                    AS recommendedR,
  ISNULL(ce.OPERATIONL, '')                    AS recommendedL,
  ISNULL(opReg.regDate, '')                    AS surgeryRegDate,
  ISNULL(opRsv.RESERVE_DATE, '')               AS surgeryReserveDate,
  ISNULL(COALESCE(NULLIF(LTRIM(RTRIM(op.OPERATIONR_DATE)),''), NULLIF(LTRIM(RTRIM(op.OPERATIONL_DATE)),'')), '') AS surgeryDate,
  ISNULL(op.OPERATIONR, '')                    AS surgeryR,
  ISNULL(op.OPERATIONL, '')                    AS surgeryL,
  ISNULL(COALESCE(NULLIF(LTRIM(RTRIM(osr.EMP_NAME)),''), NULLIF(LTRIM(RTRIM(osl.EMP_NAME)),'')), '') AS surgeon,
  ISNULL(REPLACE(CONVERT(varchar(30), CONVERT(money, NULLIF(pay.RECEIPT, 0)), 1), '.00', ''), '') AS payment,
  ISNULL(ec.EMP_NAME, '')                      AS counselor,
  ISNULL(ed.EMP_NAME, '')                      AS doctor,
  ''                                           AS jumin,
  ISNULL(cu.BIRTH_DAY, '')                     AS birth,
  CASE WHEN cu.LUNAR_YN = 'Y' THEN '음' ELSE '양' END AS lunar,
  ISNULL(cu.CALL_NUM1, '')                     AS phone1,
  ISNULL(cu.CALL_NUM2, '')                     AS phone2,
  ISNULL(cu.EMAIL, '')                         AS email,
  ISNULL(LTRIM(RTRIM(cu.ZIP_CODE)), '')        AS zip,
  ISNULL(cu.ADDR1, '')                         AS addr1,
  ISNULL(cu.ADDR2, '')                         AS addr2,
  ISNULL(cu.ETC, '')                           AS memo,
  ISNULL(LTRIM(RTRIM(ce.Stop_YN)), '')         AS examStop,
  ISNULL(LTRIM(RTRIM(ce.Impossible)), '')      AS opImpossible,
  ISNULL(rsv.RESERVE_PATH, '')                 AS route,
  ISNULL(motive.section, '')                   AS section,
  ISNULL(motive.motiveL, '')                   AS motiveL,
  ISNULL(motive.motiveM, '')                   AS motiveM,
  ISNULL(motive.motiveS, '')                   AS motiveS,
  ISNULL(motive.motiveMemo, '')                AS motiveMemo,
  ISNULL(eo.EMP_NAME, '')                      AS optometrist,
  ISNULL(LTRIM(RTRIM(ce.Cancel_CD)), '')       AS cancelCode,
  ISNULL(NULLIF(ce.Cancel_reason, ''), ISNULL(cc.CANCEL_REASON, '')) AS cancelMemo,
  ISNULL(cu.LEVEL, '')                         AS grade,
  ISNULL(cu.JOB, '')                           AS job,
  ISNULL(cu.LAST_DAY, '')                      AS lastVisit,
  ISNULL(ins.EtcCodNam, '')                    AS insurance,
  ISNULL(nation.Nation_CodeName, '')           AS nationality
FROM Cataract_Exam ce WITH(NOLOCK)
JOIN CUSTOM cu WITH(NOLOCK)                       ON ce.CUST_NUM = cu.CUST_NUM
LEFT JOIN Cataract_Operationdata op WITH(NOLOCK)  ON ce.CUST_NUM = op.CUST_NUM
LEFT JOIN EMPLOYEE osr WITH(NOLOCK)               ON op.OPERATIONR_DOC = osr.EMP_NUM
LEFT JOIN EMPLOYEE osl WITH(NOLOCK)               ON op.OPERATIONL_DOC = osl.EMP_NUM
LEFT JOIN EMPLOYEE ec WITH(NOLOCK)                ON cu.MY_COUNSELOR   = ec.EMP_NUM
LEFT JOIN EMPLOYEE ed WITH(NOLOCK)                ON cu.MY_DOCTOR      = ed.EMP_NUM
LEFT JOIN EMPLOYEE eo WITH(NOLOCK)                ON cu.MY_OPTOMETRIST = eo.EMP_NUM
LEFT JOIN CANCEL_CFG cc WITH(NOLOCK)              ON ce.Cancel_CD      = cc.CANCEL_CD
LEFT JOIN NationCustom_CFG nation WITH(NOLOCK)    ON cu.Nation_code    = nation.Code
LEFT JOIN EtcCfg ins WITH(NOLOCK)
  ON ins.EtcBseCod = 'InsuranceCfg' AND ins.EtcCod = cu.InsuranceCode
OUTER APPLY (
  SELECT TOP 1 r.RESERVE_FLAG, r.RESERVE_JINRYO, r.START_TIME, r.RESERVE_PATH, r.RESERVE_NUM
  FROM RESERVATION r WITH(NOLOCK)
  WHERE r.CUST_NUM = ce.CUST_NUM AND r.RESERVE_DATE = ce.EXAM_DATE
    AND r.RESERVE_STATE IN ('I','H') AND r.RESERVE_FLAG = 'H'
  ORDER BY r.RESERVE_NUM DESC
) rsv
LEFT JOIN MEDICAL_SUB_CFG ms WITH(NOLOCK)
  ON ms.RESERVE_FLAG = rsv.RESERVE_FLAG AND ms.SUB_FLAG = ISNULL(rsv.RESERVE_JINRYO, '')
OUTER APPLY (
  SELECT CASE WHEN LEN(LTRIM(RTRIM(ISNULL(rsv.RESERVE_NUM, '')))) >= 6
              THEN '20' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 1, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 3, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(rsv.RESERVE_NUM)), 5, 2)
              ELSE '' END AS regDate
) rsvReg
OUTER APPLY (
  SELECT TOP 1 f.RESERVE_DATE, f.RESERVE_NUM
  FROM RESERVATION f WITH(NOLOCK)
  WHERE f.CUST_NUM = ce.CUST_NUM AND f.RESERVE_FLAG = 'O'
    AND f.RESERVE_JINRYO = '4'            -- 백내장 수술만(레거시 기준). 미지정 시 시력교정 수술예약이 섞임
    AND f.RESERVE_STATE <> 'C'
  ORDER BY f.RESERVE_NUM DESC
) opRsv
OUTER APPLY (
  SELECT CASE WHEN LEN(LTRIM(RTRIM(ISNULL(opRsv.RESERVE_NUM, '')))) >= 6
              THEN '20' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 1, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 3, 2)
                 + '-' + SUBSTRING(LTRIM(RTRIM(opRsv.RESERVE_NUM)), 5, 2)
              ELSE '' END AS regDate
) opReg
OUTER APPLY (
  SELECT TOP 1
    ISNULL(m2.category01_name, '') AS motiveL,
    ISNULL(m2.category02_name, '') AS motiveM,
    ISNULL(m2.category03_name, '') AS motiveS,
    ISNULL(NULLIF(m1.comments, ''), ISNULL(m2.name, '')) AS motiveMemo,
    ISNULL(CONVERT(varchar(10), m2.[section]), '') AS section
  FROM MOTIVE_NEW02 m2 WITH(NOLOCK)
  LEFT JOIN MOTIVE_NEW01 m1 WITH(NOLOCK) ON m2.fkey = m1.pkey
  WHERE m2.cust_num = ce.CUST_NUM AND m2.Idx = '1'
  ORDER BY m2.pkey DESC
) motive
LEFT JOIN (
  SELECT TMP.PRC_CUSNUM, SUM(TMP.RECEIPT) AS RECEIPT
  FROM (
    SELECT A.CUST_NUM AS PRC_CUSNUM, SUM(ISNULL(A.COST_PRICE, 0)) AS RECEIPT
    FROM COSTPRICE A WITH(NOLOCK)
    LEFT JOIN (SELECT CstCusNum, CstSeq FROM CSTPRCSUB WITH(NOLOCK) GROUP BY CstCusNum, CstSeq) B
      ON A.CUST_NUM = B.CstCusNum AND A.SEQ = B.CstSeq
    LEFT JOIN (SELECT PrcCusNum, PrcSeq FROM PRCITMLST WITH(NOLOCK) GROUP BY PrcCusNum, PrcSeq) C
      ON A.CUST_NUM = C.PrcCusNum AND A.SEQ = C.PrcSeq
    WHERE B.CstCusNum IS NULL AND C.PrcCusNum IS NULL
      AND A.COST_FLAG IN ('O','I','H') AND UPPER(ISNULL(A.PayStt, '')) <> 'A'
    GROUP BY A.CUST_NUM
    UNION ALL
    SELECT B.CstCusNum AS PRC_CUSNUM, SUM(ISNULL(B.CstPrc, 0)) AS RECEIPT
    FROM COSTPRICE A WITH(NOLOCK)
    JOIN CSTPRCSUB B WITH(NOLOCK)
      ON A.CUST_NUM = B.CstCusNum AND A.SEQ = B.CstSeq
     AND A.COST_FLAG IN ('O','I','H') AND B.CstCnlYnN = 'N' AND B.CstPayTyp = 'N'
    LEFT JOIN PRCITMLST C WITH(NOLOCK) ON B.CstCusNum = C.PrcCusNum AND B.CstSeq = C.PrcSeq
    WHERE C.PrcCusNum IS NULL AND UPPER(ISNULL(A.PayStt, '')) <> 'A'
    GROUP BY B.CstCusNum
    UNION ALL
    SELECT T2.CUST_NUM AS PRC_CUSNUM,
           SUM(CASE D.PrcCnlYnN WHEN 'Y' THEN 0 ELSE ISNULL(D.PrcDtlPrc, 0) END) AS RECEIPT
    FROM (SELECT DISTINCT A.CUST_NUM, A.SEQ FROM COSTPRICE A WITH(NOLOCK)
          WHERE ISNULL(A.COST_FLAG, '') = '' AND UPPER(ISNULL(A.PayStt, '')) <> 'A') T2
    JOIN PRCITMLST C WITH(NOLOCK) ON T2.CUST_NUM = C.PrcCusNum AND T2.SEQ = C.PrcSeq AND C.PrcCod IN ('O','I','H')
    JOIN PrcItmDtl D WITH(NOLOCK)  ON T2.CUST_NUM = D.PrcCusNum AND T2.SEQ = D.PrcSeq AND D.PrcCod IN ('O','I','H')
    GROUP BY T2.CUST_NUM
  ) TMP
  GROUP BY TMP.PRC_CUSNUM
) pay ON ce.CUST_NUM = pay.PRC_CUSNUM AND ce.CUST_NUM <> '9999999999999'
WHERE ce.EXAM_DATE >= :from AND ce.EXAM_DATE <= :to
  AND NOT (
    ISNULL(cu.CUST_NAME, '') LIKE N'%테스트%'
    OR LOWER(ISNULL(cu.CUST_NAME, '')) LIKE '%test%'
  )
ORDER BY ce.EXAM_DATE, rsv.START_TIME, cu.CUST_NAME
```

> 시력교정 검사자 리스트 SQL과 차이: ① 본 테이블 `Cataract_Exam`(고객당 복수 `SEQ` 가능) ② 예약 조인 `RESERVE_FLAG='H'` ③ 수술불가 `Impossible`·취소메모 `Cancel_reason` ④ 좌/우 집도의(`OPERATIONR_DOC`/`OPERATIONL_DOC`) `COALESCE` ⑤ 견적가 좌/우 결합 ⑥ 백내장 그림자 행 제외 조건 없음(시력교정 전용 보정). 위 SQL은 [CataractExamListRepository.java](../../backend/src/main/java/com/bviit/analytics/exam/repository/CataractExamListRepository.java) `findCataractExamList`와 동일한 전문.

### 1. 데이터 소스 (쿼리 구조)

디컴파일 문자열결합 SQL을 재구성한 골격 (**radCustom = 고객당 1행** 분기):

```sql
SELECT A.*,                                            -- Cataract_Exam 전체(검사정보·견적·영업가율 등)
   B.OperationR_Date, B.OperationL_Date,               -- 좌/우 수술일
   B.OperationR [OP_OPR], B.OperationL [OP_OPL],       -- 좌/우 수술방법(실제)
   C.emp_name [OperationR_Doc_Name], D.emp_name [OperationL_Doc_Name],  -- 좌/우 집도의
   E.Cust_name, E.Call_Num2, E.Zip_Code, E.Addr1, E.Addr2, E.Etc, E.Job, E.Post_LK,
   ShortJumin [JUMIN_NUM] /* 보안DB면 @SEC_JUMIN */,
   F.emp_name [My_Counselor_Name], G.emp_name [My_Doctor_Name], L.emp_name [My_Optometrist_Name],
   (SELECT NAME FROM MOTIVE_CATEGORY01 WHERE PKEY=K.CATEGORY01_KEY) [CATEGORY01_NAME],   -- 내원동기 대
   (SELECT NAME FROM MOTIVE_CATEGORY02 WHERE PKEY=K.CATEGORY02_KEY) [CATEGORY02_NAME],   -- 중
   (SELECT NAME FROM MOTIVE_CATEGORY03 WHERE PKEY=K.CATEGORY03_KEY) [CATEGORY03_NAME],   -- 세
   (SELECT TOP 1 COMMENTS FROM MOTIVE_NEW01 WHERE CUST_NUM=K.CUST_NUM) [COMMENTS],       -- 동기메모
   (SELECT TOP 1 ... FROM RESERVATION F WHERE RESERVE_FLAG='O' ... ) AS PRE_DATE,        -- 수술예약일
   I.RESERVE_DATE [OP_RESERVE_DATE],
   (SELECT EtcCodVal FROM EtcCfg WHERE EtcBseCod='InflowItemCfg' AND EtcCod=A.InflowCod) [Inflow_Name],  -- 유입
   (SELECT EtcCodNam FROM EtcCfg WHERE EtcBseCod='InsuranceCfg' AND EtcCod=E.InsuranceCode) [InsuranceName], -- 실손
   NC.Nation_CodeName,                                 -- 국적
   TMP2.*                                              -- 가격/수납 집계(아래)
FROM Cataract_Exam A
   LEFT JOIN Cataract_Operationdata B ON A.Cust_num = B.Cust_num
   LEFT JOIN Employee C ON B.OperationR_Doc = C.Emp_num     -- 우안 집도의
   LEFT JOIN Employee D ON B.OperationL_Doc = D.Emp_num     -- 좌안 집도의
   LEFT JOIN Custom   E ON A.Cust_num = E.Cust_num
   LEFT JOIN Employee F ON E.My_Counselor   = F.Emp_num     -- 상담사
   LEFT JOIN Employee G ON E.My_Doctor      = G.Emp_num     -- 상담의
   LEFT JOIN Employee L ON E.My_Optometrist = L.Emp_num     -- 검안사
   LEFT JOIN MOTIVE_NEW02 K ON A.CUST_NUM = K.Cust_num AND K.idx='1'
   LEFT JOIN RESERVATION I (최신 수술예약 O) ...
   LEFT JOIN NationCustom_CFG NC ON E.Nation_code = NC.code
   LEFT JOIN ( COSTPRICE + CSTPRCSUB + PRCITMLST + PrcItmDtl 4단 집계
               → PRC_PRICE(납부)/RECEIPT(수납)/OSD_PRC(미수)/OP_PRC(수술금액) ) TMP2 ON A.CUST_NUM=TMP2.PRC_CUSNUM
WHERE Exam_Date BETWEEN @from AND @to
  AND (My_Counselor=@counselor OR @counselor='-1')
  AND (My_Doctor=@doctor       OR @doctor='-1')
  AND (My_Optometrist=@optom   OR @optom='-1')
  /* radLast: AND Exam_Date IN (SELECT MAX(Exam_Date) ...) */
  /* CkExcept: AND Cust_num NOT IN (SELECT Cust_num FROM Cataract_Exam WHERE Impossible='Y' OR Stop_YN='Y') */
ORDER BY Exam_Date
```

**radODOS = 좌/우안 각 1행** 분기: 내부 파생테이블에서 `'OD', OPERATIONR, OPERATIONR_DATE, OP_ESTIMATE_R, RIGHT01..15` / `'OS', OPERATIONL, ..., LEFT01..15` 를 `UNION ALL` 로 펼침 (`WHERE OPERATIONR<>''` / `OPERATIONL<>''`). 정렬 `ORDER BY CUST_NUM, EXAM_DATE`.

> 출처: `SoftCrm.decompiled.cs` `FrmCataract_ExamList`(745768~749152). 원본은 **문자열결합 + string.Format**(바인딩 아님) → 이식 시 파라미터 바인딩 필수.

| 분류 | 컬럼 |

| 수술권고 | `OPERATIONR`/`OPERATIONL`(nvarchar40), `Impossible` |

### 4. ★ 시력교정(검사자 리스트)과의 핵심 차이 — 구현 시 주의

| 항목 | 시력교정 (검사자 리스트) | **백내장 (본 화면)** |
|------|------------------------|---------------------|
| 검사 소스 | `EXAM` (고객당 **1행 스냅샷**) | `Cataract_Exam` (`CUST_NUM`+**`SEQ`**, 복수행 가능) |
| 수술 소스 | `OPERATIONDATA` | `Cataract_Operationdata` |
| 수술불가 | `OP_POSSIBLE_YN` | **`Impossible`** |
| 취소사유메모 | `CANCEL_REASON` | **`Cancel_reason`** |
| 검사정보 | RIGHT/LEFT **01~30** (30쌍) | RIGHT/LEFT **01~15** (15쌍, 그리드) |
| 견적가 | `OP_ESTIMATE` (단일) | **좌/우 분리** `OP_ESTIMATE_R`/`_L` + `OP_UnitPrice_R`/`_L`(money) |
| 집도의 | (placeholder) | **좌/우 분리** `OperationR_Doc`/`OperationL_Doc` → EMPLOYEE |
| 다초점 단서 | 없음 | **`FocalDistance`**(초점거리, 단 그리드 미노출) |
| 내원동기·국적·실손·유입 | 검사자리스트 §6 placeholder(미확정) | **본 화면엔 실제 조인 존재**(MOTIVE_NEW02·NationCustom_CFG·EtcCfg) → 시력교정 placeholder 해소 참고 가능 |
| 좌/우안 뷰 | 없음 | **radODOS** 눈 단위 행 분리 지원 |

> ⚠️ **biometry 전용 컬럼(IOL 도수/모델, 안축장 AL, 각막곡률 K, 전방깊이 ACD, 목표굴절) 없음.** 백내장 검사 리스트는 "임상 biometry 리포트"가 아니라 **검사·수술·매출·동기 관리 리포트**다. AL/K/ACD/IOL을 운영상 `RIGHT/LEFT01~15` 자유슬롯에 넣었을 수는 있으나 라벨에 의미가 명시돼 있지 않다(범용 슬롯). 필요하면 검사입력 화면의 항목 매핑표 또는 EyeChartPro 장비연동을 별도 확인.

### 5. 함정 (Gotchas)

- **복수행(SEQ)**: `Cataract_Exam`은 고객당 여러 검사행(`SEQ`) 가능. 시력교정 EXAM처럼 "고객=1행" 가정 금지. `radLast`(최근검사만) 옵션이 `MAX(EXAM_DATE)` 필터로 이를 처리.
- **좌/우안 이원화**: 견적·수술방법·수술일·집도의가 R/L 컬럼으로 갈림. "건수"는 뷰(고객/눈)에 따라 의미가 다름 — 지표정의 §1.4 백내장은 **추천 눈 단위**(`OPERATIONR`/`OPERATIONL` 채움) 집계임을 상기.
- **money 타입**: `OP_UnitPrice_R/L`은 money. 수납금액(`RECEIPT`)은 별도 `COSTPRICE` 4단 집계라 단순치 않음(원데이 합산 함정, [tables/COSTPRICE.md](tables/COSTPRICE.md)).
- **검사정보 라벨 부재**: RIGHT/LEFT 인덱스에 고정 임상 라벨 없음(병원/장비 설정 의존). 시력교정과 동일 주의.
- **원본 SQL Injection**: 문자열결합 + string.Format. 이식 시 파라미터 바인딩 필수.
- **JUMIN 복호화**: 보안DB면 `@SEC_JUMIN` 분기 — [tables/CUSTOM.md](tables/CUSTOM.md).

### 6. 다음 단계 (구현 시)

검사자 리스트와 동일 패턴으로 `/api/cataract-exam-list` 구현 가능:
- 소스만 `Cataract_Exam`+`Cataract_Operationdata`로 교체, `Impossible`/`Cancel_reason`/15쌍 반영.
- 내원동기·국적·실손·유입은 본 화면 조인이 확정돼 있어 **placeholder 없이 실데이터** 가능.
- 눈 단위(radODOS) vs 고객 단위(radCustom) 뷰 토글 여부 결정 필요.
