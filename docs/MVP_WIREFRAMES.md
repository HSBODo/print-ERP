
**필드·동작**
- LOT.NO: 저장 시 서버에서 `CI{YYMM}-{NNNN}` 자동 할당. "수동 입력" 토글 시 free text.
- 고객명: Combobox, 입력 중 기존 고객명 자동완성. 신규 입력 시 "신규 고객 추가" 버튼
- 제품코드: 동일 Combobox. 선택 시 제품명 자동 채움
- 공정 체크박스: 5개 중 1개 이상 필수
  - 각 공정 옆에 "외주" 체크박스 → WorkOrder.isOutsourced
- 저장 → 서버에서 WorkOrder N건 자동 생성 (선택한 공정 × 1건씩)
- 수정 화면(`/orders/$id`): 동일 폼 + 상단에 "수주 상태" 표시
  - 이미 실적이 입력된 공정은 공정 체크 해제 금지(백엔드 검증)

**유효성 (Zod 스키마)**
```ts
z.object({
  lotNo: z.string().optional(),      // 자동 생성 시 생략
  orderDate: z.date(),
  dueDate: z.date(),
  customerName: z.string().min(1),
  productCode: z.string().min(1),
  productName: z.string().min(1),
  quantity: z.number().positive(),
  processRoute: z.array(z.object({
    process: z.enum(['PRINT','LAMINATION','DRY','SLITTER','OTHER']),
    isOutsourced: z.boolean().default(false),
    otherText: z.string().optional(),    // OTHER 선택 시
  })).min(1),
  remarks: z.string().optional(),
})
```

**사용 shadcn 컴포넌트**
- `Form`, `Input`, `Combobox`(cmdk), `Checkbox`, `Textarea`, `DatePicker`, `Button`, `Card`

**필드·동작**
- 상단 탭: 공정 enum 5개, 각 탭 라벨 옆 괄호에 해당 공정의 미완료 건수 뱃지
- 탭 전환 시 라우트 searchParam `?process=PRINT` 변경 (URL로 북마크 가능)
- 상태 필터: 미완료 / 완료 토글
- 각 카드 = 1 WorkOrder
  - 좌측: 수주 정보 (LOT.NO, 고객, 제품명, 재질, 작업량, 외주 벤더)
  - 우측: 납기 D-day (D-2 이하는 🔴)
  - 하단: **투입량·생산량 인라인 입력** + 저장 버튼 + 완료 처리 버튼
- 인라인 입력 = 공장 담당자 UX 우선 (다이얼로그 띄우지 않음)
- "실적 저장" → `completed` 는 유지, 수치만 업데이트
- "완료 처리" → `completed=true`, 큐에서 숨김 (완료 탭에서 조회)

**실적 저장 시 유효성**
- 투입량 < 생산량 이면 노란색 경고 (초과 생산 — 과거 데이터 사례 다수)
- 투입량 0, 생산량 0 으로 저장은 허용 (대기 상태)

**사용 shadcn 컴포넌트**
- `Tabs`, `Card`, `Input`, `Button`, `Badge`, `RadioGroup`, `ScrollArea`

## 8. 라우트 구조 (TanStack Router 파일 트리)

```
src/routes/
├─ __root.tsx
├─ login.tsx                       (템플릿)
└─ _auth/
   ├─ route.tsx                    (인증 가드 — 템플릿)
   ├─ index.tsx                    (홈 — 수주 목록으로 리다이렉트)

   │  ├─ layout/                   (사이드바·상단바 — 템플릿)
   │  └─ navigation.ts             (신규 메뉴 추가)
   ├─ orders/
   │  ├─ index.tsx                 (목록)
   │  ├─ new.tsx                   (신규)
   │  └─ $orderId.tsx              (수정·상세)
   ├─ workorders/
   │  └─ index.tsx                 (공정 큐, searchParam 으로 탭 전환)
   └─ admin/
      └─ accounts.tsx              (템플릿)
```

## 9. 화면별 API 매핑

| 화면 | 메서드 | 경로 |
|---|---|---|
| 수주 목록 | GET | `/api/orders?from&to&customer&status&page` |
| 수주 목록 CSV | GET | `/api/orders/export.csv?from&to&customer&status` |
| 수주 상세 | GET | `/api/orders/{id}` |
| 수주 등록 | POST | `/api/orders` |
| 수주 수정 | PUT | `/api/orders/{id}` |
| 수주 삭제 | DELETE | `/api/orders/{id}` |
| 고객 자동완성 | GET | `/api/customers?q=` |
| 제품 자동완성 | GET | `/api/products?q=` |
| 공정 큐 조회 | GET | `/api/workorders?process=&completed=&page` |
| 실적 저장 | PATCH | `/api/workorders/{id}` (body: inputQty, outputQty, remarks) |
| 완료 처리 | POST | `/api/workorders/{id}/complete` |
